# INFLUENCE RANK OPTIMIZATION

## NO_STABLE_INFLUENCE_RANK

人気順を、勝率・3着内の取りこぼし・NDCG のどれでも安定して超えるウェイトは無かった。券の研究には進んでいない。本番の影響率ファイルは変更していない。

## 既存実装

詳細は `repo/influence_rank_forensics.md`。保存ウェイトでゼロでないのは Base 1.0、人気 1.5、当日スキャンの ScoringSignal 1.0、騎手力トップ3 0.1。合成はレース内の最小最大で 0–100 にした値にウェイトを掛け、予測スコアの降順が Rank になる。ScoringSignal と Projected Score の材料は過去再現できないので、最適化には入れていない。

## 使った列

市場を見ない版: VH、能力指数（向き反転）、H7、末脚平均、過去3着内率、騎手の場別勝率、調教師の場別3着内率、消去数（向き反転）。

市場を見る版: 上記に人気（向き反転）を足した。

ロジスティック回帰（標準化、C=1、目的は勝ちラベル）。ROI は目的に入れていない。各年の係数は、その年より前だけで学習した。
