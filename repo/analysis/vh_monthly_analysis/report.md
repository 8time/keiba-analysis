## 10. 本番VH仕様（調査結果）

| 項目 | 内容 |
|---|---|
| 本番モジュール | `core/value_hunter.py`（軽量7特徴ロジスティック） |

| 広域網閾値 | recall0.7 ≥ 0.0827 |
| 複数頭 | レース内で該当する全頭を表示（精鋭/広域網/その他） |
| オッズ取得 | 出走表スクレイプ時点（当日） |
| 対象 | JRA中央（jyo≤10） |
| 検証データ | horse_races.csv 20160105〜20260621 |
