# VH ティア別・候補密度 追加検証

本番ロジックは変更なし。既存VH候補の集計分割のみ。

## 最終判定

### 1. VHは9月に弱いのか

- **いいえ（全体）**。C群9月1着率 3.94% vs その他 3.8%（p≈0.5529）

### 2. 🎯精鋭は9月に弱いのか

- **いいえ**。A群9月1着率 4.47% vs その他 4.56%（p≈0.7817）
- 複勝率: 9月 19.06% vs その他 18.53%（p≈0.3714）

### 3. 🕸️広域網は9月に弱いのか

- **全期間ではいいえ**。B群9月1着率 2.99% vs その他 2.37%（p≈0.048）→ 9月の方がやや高い。
- **2025年holdoutのみ**: 9月1着率 1.85% / 単勝回収率 51.0% と低い（271頭・断定は不可）。
- 2025年9月の全体低下は**広域網側の寄与が大きい**。精鋭は 4.17% / 87.7% で通常月並み。

### 4. 候補数を増やしても9月性能は維持されているのか

- 精鋭→精鋭+広域網で1着率: 4.55% → 3.81%
- 複勝率: 18.56% → 16.12%
- 単勝回収率: 83.3% → 81.86%
- 候補を増やすと1着率・回収率はやや下がるが、9月だけ特異的に崩れるわけではない。

### 5. きういとの比較は直接可能か

- **現時点では直接比較不可**（選定条件・候補密度が大きく異なる）。
- 参考集計（精鋭×オッズ5倍+）でも頭数はきうい109頭と一致しない。
- 参考②: 9月 4628頭 / 1着率 4.47% / 単勝回収率 88.74%
- **注**: ②は①と同一結果。6番人気以下の精鋭は全頭オッズ5倍以上（中央値19.75倍）のため、オッズ5倍+フィルタは実質無効。
