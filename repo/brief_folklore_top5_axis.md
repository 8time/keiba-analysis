# 俗説総合TOP5 × 1〜3番人気は軸になるか

> 実装しない。このファイルを渡してバックテストだけやる。
> holdout で残差が出なければ、軸信頼度にも俗説ハンターにも足さない。

---

## 0. いま何を確かめるか

俗説ハンターの **⭐ 総合 TOP5** に、1〜3番人気が入っていると軸に使えそうに見える。

問いは2つ。どちらも「生の複勝率が高い」では足りない。人気1〜3はもともと3着以内が多い。

1. **総合TOP5に入った1〜3番人気は、同じ人気の平均より3着以内が多いか。**
2. **1〜3番人気がTOP5に複数入ったとき、総合の上位の方が、人気順より軸として良いか。**

画面の総合は「買いの個数 − 消しの個数」。今の予想の軸（人気1+2、オッズ複勝率）とは別物。

---

## 1. やってはいけないこと

- 着順・通過・結果脚質で総合を作る
- 人気をならさずに「複勝70%だから軸」と言う
- train で一番良かった切り方（TOP3 / 1番人気だけ / 2頭以上だけ）を後から選ぶ
- 総合の中身の俗説を足したり外したりして、良い数字だけ残す
- Rank / 穴馬ハンター / `axis_selector` / 3連単に足す
- `recommend_trio` / `fixed_pool` のシグネチャを変える
- 新ライブラリを足す

holdout で再現しなければ却下。画面に「軸向き」とも出さない。

---

## 2. 総合の定義（固定）

ライブ画面と同じ関数を使う。`core.folklore_lib.evaluate_horse` の  
`score = n_pos - n_neg`。

馬の材料は CSV（`scripts/csv_data.py`）の事前確定列だけ。

- 枠・人気・オッズ・馬体重増減・休み・距離増減・芝ダ・場・頭数・性別・斤量・ハンデ・新馬/オープン
- 前走の通過順・前走着順・パドックは CSV に無いので、その俗説は当たったことにしない（画面より薄い）

レース内の並びは画面と同じ。

`(-score, n_neg, -n_pos, umaban)` の順。上から5頭が TOP5。

1〜3番人気 = `ninki` が 1, 2, 3。

---

## 3. 窓

| 窓 | 定義 | 使い方 |
|---|---|---|
| train | `day <= 20241231` | 人気別ベース複勝。符号の確認 |
| holdout | 2025年 | 採否の本番 |
| recent | `day >= 20260321` | 直近で崩れないか |

人気別ベースは **train の全馬** だけ。holdout で作り直さない。

最低標本: 頭の判定は **n≥200**。レース単位は **≥80R**。足りなければ判定不能。

---

## 4. 見るテスト（これ以外に切らない）

### A. TOP5に入った1〜3番人気

対象: `ninki<=3`

- **IN** = そのレースの総合TOP5に入っている
- **OUT** = 1〜3番人気だがTOP5に入っていない

主指標: IN の **複勝残差**（実3着以内 − その人気のtrain平均）。

IN の人気の内訳（1番人気が何割か）も出す。1番人気ばかり拾っているだけ、を見るため。

### B. 1〜3番人気がTOP5に2頭以上

対象レース: IN が2頭以上。

その2頭以上のうち、

- **総合いちばん上**
- **人気いちばん上**（同じ集合の中）

が違う馬のときだけ、3着以内率を比べる。同じ馬なら「どちらでも同じ」で数えない。

### C. 軸2頭（両方3着以内）

対象は B と同じレース。

- **いまの軸** = 人気1と人気2（TOP5に入っていなくても）
- **総合の軸** = IN の上位2頭

両方3着以内の率を、同じレースで比べる。

---

## 5. 採否（後から下げない）

採用は **A の holdout** が全部満たすときだけ。

| 条件 | 値 |
|---|---|
| holdout 複勝残差 | **+3.0pp 以上** |
| holdout z | **+2.0 以上** |
| train 残差 | プラス（符号だけ。覗き見対策） |
| n | ≥200 |

B と C は「複数入ったら上位を軸にする」用。A が未達なら見ない。

B: 違う馬のとき、総合いちばん上が人気いちばん上より holdout で **+2.0pp 以上**（3着以内）。n≥200。

C: 総合の軸2頭が、人気1+2より holdout で **+2.0pp 以上**（両方3着以内）。レース ≥80R。

1つでも欠ければ **不採用**。軸信頼度は変えない。俗説ハンターに「軸向き」とも出さない。
