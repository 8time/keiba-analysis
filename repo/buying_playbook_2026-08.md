実配当34,212レース（2016-2026）と、vh2/LTRの学習期間外にあたる4,754〜4,781レース
（2025-2026）で測った結果。**全ての数字は実配当ベースの実測**。

> ⚠️ **前提**: 全ゾーン・全形で回収率100%未満。控除率25%（ROI75%が基準）は超えるが
> 100%には届かない。ここに書いてあるのは「勝てる買い方」ではなく
> **「負けが最も浅い買い方」**。

## 1. 【最重要】ゾーンごとに「人気」と「Rank」の優劣が入れ替わる

**人気が+7〜9pp勝ち**。的中率も29.3% vs 23.1%と大差。

### C 中庸（妙味度50-69・1,930レース）→ **Rankが勝つ**
| 買い方 | 点 | 的中率 | ROI |
|---|---|---|---|

**Rankが+3〜8pp勝ち**。3つの対応するペア全てでRankが上回る。

**独立した2つ目の証拠**: Rank形（a-b-c）でも同じ結論。
2025-2026だけで測ると **C中庸限定の3連単 Rank2-4-7（30点）が的中7.9% / ROI92%** で、
全レース対象の同じ形（80%）を12pp上回る。

**✅ holdout追試済み（2026-08-07）**: LTRの学習は≤2023なので **2024-2026が本番**。
穴を使わない純粋比較（◎〇固定+3頭目の3連複3点）でROI差（Rank−人気）:

| ゾーン | 2016-2020(学習内) | 2021-2023(学習内) | **★2024-2026(学習期間外)** |
|---|---|---|---|
| D 鉄板 | +0.9 | -1.3 | **-7.2（人気勝ち）** |
| **C 中庸** | **+5.2** | +1.7 | **+3.9（Rank勝ち）** |
| B/A 荒れ | -5.0 | +8.9 | -12.3（ノイズ） |

C中庸の3連単Rank2-4-7も、全レース対象との差が3窓すべてで **+15.9/+11.3/+14.4**。
**ゾーンによる逆転は学習期間外でも確認された＝本物。**
荒れだけは符号がバラバラでノイズなので、Rankも人気も当てにしない。

**解釈**: D鉄板は市場に情報が集まっていて正確なので人気が勝つ。
C中庸は市場が迷う領域なのでモデルの出番がある。荒れは両方だめ。

## 1-B. 🧠 Rank の信頼度は「クラス」で変わる（2026-08 追加）

上のゾーン（妙味度）とは**別軸**の発見。`scripts/class_rank_vs_ninki.py`・485,998頭。

### 何を測ったか（ここを取り違えると無意味）

**「Rank が当たるか」ではなく「市場の人気順位を超える情報を Rank が持っているか」**。
生の的中率で比べると「上級クラスほど強い馬が揃っている」だけの話になるので、
**クラス×人気順位別の3着内率を train で凍結し、その残差**で測った。

### 結果：下級クラスほど Rank が効く

| クラス | 信頼度 | holdout 残差 | z | 95%CI |
|---|---|---|---|---|
| 🟢 新馬 | ★★★ | +2.87pp | +3.08 | [+1.00, +4.85] |
| 🟢 **未勝利** | **★★★** | **+4.37pp** | **+9.88** | [+3.41, +5.23] |
| 🟢 1勝 | ★★★ | +2.81pp | +5.41 | [+1.77, +3.94] |
| 🟢 2勝 | ★★★ | +2.77pp | +3.90 | [+1.27, +4.24] |
| 🟡 3勝 | ★★ | +1.43pp | +1.36 | [-0.68, +3.71] |
| 🟡 OP/L | ★★ | +1.35pp | +1.07 | [-1.23, +4.04] |
| 🟡 重賞 | ★★ | +2.20pp | +1.63 | [-0.38, +5.03] |

- **★★★**（新馬・未勝利・1勝・2勝）= train と holdout の両方で z≥2、bootstrap CI が 0 を跨がない
- **★★**（3勝・OP/L）= holdout で有意でなく効果量も最小。**Rank を過信しない**
- **★★（重賞）= 判定保留**。効果量 +2.20pp は中位だが holdout n=975 で標本不足。
  **「重賞では Rank が弱い」とは断定しない**（有意な証拠が得られていないだけ）

補足: Spearman(順位, 着順) の差は**全クラスで負**＝どのクラスでも Rank の方が着順をよく説明する。
上の表は「その上に、人気を統制してもなお上乗せがあるか」を見たもの。

### ⚠ 「Rank が強い ＝ Rank1位を買え」ではない

検証したのは **「Rank 上位3頭が、人気順位から予想される以上に3着内へ来るか」**。
Rank 単独で買う話ではない。使い方は **人気 × Rank × 妙味度 の中で Rank の重みを変える**。

```
未勝利で「人気5位だが Rank1位」   → Rank を無視しない（★★★）
重賞で「人気5位だが Rank1位」     → 今回の結果だけを理由に強気にしない（★★）
```

なお複勝ROIは最も強い未勝利でも **84.8%＝100%未満**。
順位付けの精度は上がるが、控除率は破れない（[[verified_tansho_roi_efficient]]と整合）。

### ゾーン軸との関係

妙味度ゾーン（D鉄板=人気 / C中庸=Rank）とは**独立した別軸**。
両方を掛け合わせた場合の挙動（交互作用）は未検証なので、
現状は「C中庸で Rank 系を使うとき、クラスが 3勝/OP-L なら控えめに」程度の
**信頼度の重み付け**にとどめる。

## 2. 実用形（ゾーン別の推奨）

### 🟢 D 鉄板（妙味度0-49）— **メインで買う**
```
効率で選ぶ  ◎-〇-人気3番 / ◎-〇-人気4番        2点   的中23.5% / ROI90%
的中で選ぶ  上記 + ◎-〇-穴1位 / ◎-〇-穴2位     4点   的中31.5% / ROI89%
```
◎=人気1番 / 〇=人気2番 / 穴=人気6番以下でvh2最大。全券に◎〇を固定する。
**2点なら1レース200円**。投資額も最小で効率も最良。

### 🟡 C 中庸（妙味度50-69）— **3連単でRankを使う**
```
3連単  Rank 2-4-7（30点）                      的中7.9% / ROI92%
3連複  ◎-〇-Rank3位 / ◎-〇-Rank4位 + 穴1-2位   的中11.0% / ROI86%
```
Rank2-4-7＝1着候補Rank1-2位 / 2着Rank1-4位 / 3着Rank1-7位。
**このゾーンだけ3連単が3連複を明確に上回る**。

### 🔴 B/A 荒れ（妙味度70-）— **見送り**
最良でも84%（37点＝3,700円必要）。D鉄板の90%（2点＝200円）に全く届かない。
**買わないのが正解**。

## 3. 天井と、やってはいけないこと

### 天井
- 人気1・2が**両方**3着内 = **32.0%**。◎〇固定型はこれを超えられない
- 3頭そろい（1点的中）は **3.6%** だけ
- 5着内を上位N頭で捕捉する上限は**市場**（LTR81.3% vs 人気81.7%）

### やってはいけないこと
| ❌ | 実測 |
|---|---|
| **荒れで人気1・2を外す** | 的中0.8-4.4% / **ROI40-64%** |
| 100倍超を買う | ROI **48.9%**（全帯で最悪） |
| 3連単に変える（同じ馬集合で） | 3連複79% → 3連単76%。**的中率は同一で点数6倍** |
| 点数を増やす | 点数とROIの相関 **-0.654**（絞るほど良い） |
| 追い上げ系 | 退場率 マーチン98.2% / ダランベール99.8% / **オスカー99.0%** |

### 残り1頭は何が来るか
人気1・2が3着内に入った1,528レースで、残り1枠を埋めた馬の人気:
**3番人気27.9% / 4番20.8% / 5番13.8%** → **3-5番人気で62.6%**。
6番人気以下は37.4%で、その中ならvh1位が29.7%（ランダム8%の**3.7倍**）。

## 4. 買い方の性質（続けたら何が起きるか）

| ゾーン/券種 | 点 | 的中 | ROI | 平均配当 | 中央値 | **最大連敗** | プラス年率 |
|---|---|---|---|---|---|---|---|
| D鉄板 3連複 1-3-6 | 7 | 24.4% | 74% | 2,116 | 1,150 | 30 | 0.2% |
| C中庸 3連複 1-3-6 | 7 | 10.9% | 84% | 5,431 | 2,535 | 52 | 18.9% |
| 荒れ 3連複 2-3-6 | 10 | 7.1% | 76% | 10,690 | 5,290 | **107** | 8.5% |
| D鉄板 3連単 1-4-8 | 18 | 11.5% | 71% | 11,097 | 4,860 | 83 | 3.8% |
| **C中庸 3連単 2-4-7** | 30 | 7.7% | 88% | 34,186 | 13,570 | 81 | **24.2%** |
| 荒れ 3連単 2-5-8 | 48 | 5.8% | 68% | 56,374 | 24,795 | 89 | 2.9% |

**平均配当と中央値の乖離に注意**（C中庸3連単は34,186 vs 13,570）。
ROIは一部の高配当が作っている。普段の的中はもっと安い。

**必要資金** = 1点金額 × 点数 × 実測の最大連敗 × 1.5
（C中庸3連単は1点100円でも**36.5万円**）

## 5. 資金管理

**フラットベット一択。** 500試行×1,200レースの退場率:
| 手法 | 退場率 |
|---|---|
| **フラットベット** | **2.2%** |
| パーレー | 64.8% |
| マーチンゲール | 98.2% |
| オスカーズグラインド | 99.0% |
| ダランベール | 99.8% |

ルーレットのダズン（必ず3.00倍）と違い、3連複は**最小0.33倍〜最大15.9倍**で
**当たっても10%はトリガミ**。進行法の前提「1回勝てば取り返す」が成立しない。

**「ここぞで厚く張る」の正体は「それ以外を買わない」。**
ゾーン配分を寄せてもD単独の89%に漸近するだけで超えない。しかも投資額はDのみが最小
（89万円 vs 5-1-0配分の522万円）。

**日内の流れ（hot hand）は存在しない。** その日の絶好調（的中60%+）の次は
むしろ19.8%（平均以下）。ROIも直前的中の次84% / 直前外れの次83%。

## 7. 結論を1行で

> **妙味度50未満のレースで、◎〇＋人気3-4番の3連複2点。**
> **賭け金は動かさない。動かすのは買うレースの方。**

C中庸（50-69）を買うなら3連単でRankを使う（2-4-7の30点でROI89〜92%）。
**この逆転はholdout（2024-2026）で確認済み**。
荒れ（70-）は見送る（Rankも人気も効かない）。

そのRankを使うとき、**クラスで信頼度を変える**（1-B節）：
新馬・未勝利・1勝・2勝は★★★（強く見る）／3勝・OP/Lは★★（過信しない）／
重賞は★★（標本不足で判定保留・「弱い」とは断定しない）。
