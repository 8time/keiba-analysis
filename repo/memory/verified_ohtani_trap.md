「圧勝の罠（大谷トラップ）」検証結果（scripts/ohtani_trap_backtest.py, test 2021-2025, 軸候補=1〜3番人気）。

資料(Racing Quant Dashboard)の主張＝「前走1.0秒以上で圧勝した馬は過剰人気で単勝回収66%に急落＝危険人気馬」。これを軸選定([[project_trio_engine]]の人気上位2頭軸)に転用すべきか検証 → **転用は誤り**。

- 前走圧勝(着差≥1.0秒)フラグの人気馬: **複勝率72.3% / 勝率48.2%**（n=1586）
- 同人気帯の非フラグ馬: 複勝率56.5% / 勝率23.6% → フラグ群は **複勝率+15.7pp / 勝率+24.6pp**
- 前走の勝ち幅で完全な単調性: 圧勝72.3% > 快勝(0.3-1.0)62.7% > 辛勝(<0.3)57.6% > 前走非勝利56.0%(複勝率)

**結論**: 前走圧勝の人気馬は「軸から外す」どころか **3着内信頼度が最高クラス＝最良の軸**。資料の「罠」は券種が**単勝のときだけ**真（過剰人気で単勝期待値は崩れる）。3連複の軸＝3着内信頼度(複勝率)とは別問題で、資料は的中率と回収率を混同していた。

**重要な追検証(オッズ統制)**: 上の+15.7ppは『人気(順位)』を統制した値で、交絡だった。単勝オッズ帯を固定して測り直すと、前走圧勝馬は複勝率 **-5〜-11pp(3帯一貫・小n)** ＝『オッズ相応にやや過剰人気』(資料が本来言いたかった意味)。scripts/axis_filters_backtest.py 周辺で確認。

**How to apply**: 危険人気馬検知([[project_elimination_engine]])に「前走圧勝」で軸から外す等は入れない。**軸選定の信頼度ベースはオッズ別複勝率([[project_axis_selection]])を使い、前走圧勝は『加点ではなく過剰人気注意フラグ🔨＋僅かな減点』**として扱う(オッズ欠損時のみ人気ベースで+15.7加点が有効)。単勝で買うなの注意としても有効。

**重要なDB制約**: jravan.db の `win_odds` は約63%しか入っておらず(2025年のみ83%)、欠損が群間で偏る（圧勝フラグ勝ち馬は83%欠損）。**単勝/複勝ROIの群間比較はこのDBでは不可**。検証は複勝率(3着内・完全populated)を主指標にすること。
