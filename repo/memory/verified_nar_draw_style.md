プレイブック主張「内枠×逃げが地方最強」を南関東4場119R/1,334頭で検証→**内枠加点は棄却**。

## 検証結果
- **逃げ自体は圧倒的に有利**: 勝率23.1%/複勝率51.9%(差追5.4%/19.1%の4倍)
- **内枠は逃げにプラスしない**: 内枠逃げ15.2%勝率 vs 中枠逃げ28.3% → むしろ中枠が最強
- z(勝率)=-1.22 / z(複勝)=+0.34 → 有意差なし
- 市場は内枠逃げを過大評価していない(平均4.5人気 vs 中外4.3人気)

## 対応
- スコアの逃げ×内枠+3加点 → **削除**
- DrawStyle列(枠脚) → **削除**
- 合議コメント「内枠逃げ(小回り最強型)」→ **削除**
- 逃げ自体の+4加点 → **維持**(検証で裏付け)
- Style列の逃げ表示 → 赤バッジ+ツールチップ「複勝率52%」に強化
- 合議コメント → 「逃げ馬(複勝率52%)」「先行(複勝率36%)」に変更

**Why:** 資料の主張を鵜呑みにせず検証したところ否定。逃げ優位は本物だが枠順との交互作用はない。
**How to apply:** NAR新聞で逃げを赤バッジで目立たせる。内枠加点を再提案しない。
