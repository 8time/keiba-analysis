競馬YouTube/俗説の「鉄板」シグナルは、群衆が同根拠で買う＝市場織込み済/過剰人気になりやすい。2026-06-15に5案を一括検証(scripts/folk_signals_backtest.py, test 2023-2025・JRA平地13.1万騎乗・リーク防止・オッズ補正残差)した結果、**正の妙味(買い軸)はゼロ**:

- **①初ブリンカー**: 全体 −0.011(z−1.6)、前走大敗×人気薄combo −0.020(z−1.7)=comboでも悪化。過剰人気。検知＝Alertに「🅑初ブリ」注意表示のみ(買い材料でない)。
- **②大幅距離短縮**: 大幅短縮 −0.009(z−1.9)・大幅延長 −0.009(z−2.0)=距離変更は過剰人気。むしろ「同距離±99」が +0.004(z+2.4)。俗説と逆。
- **③お帰り(得意コース戻り)**: 得意≥50% −0.004(勝利−0.006)=妙味なし。
- **④性×季節**: 唯一“実在”だが小さい。**牝×冬 −0.017(z−4.6)・牝×春 −0.012(z−3.8)=有意に過剰人気(フェード材料)**。牡×秋 +0.009(z+2.4)/牡×冬 +0.007(z+2.2)は微プラス。牝×夏 +0.005(z+1.4=有意でない)。
- **⑤初ダート5項目採点**: 初ダ全体 −0.022(z−5.9)=最強の過剰人気。好走条件該当が増えるほど悪化(score3 −0.048)。narrative完全否定。

**実装(2026-06-15)**: ④のみ採用し、牝×冬/牝×春を Ranking Table の Alert列に「♀冬ﾌｪｰﾄﾞ/♀春ﾌｪｰﾄﾞ」(青字)で**フェード注意表示**(過剰人気＝買いでなく軽い割引材料)。①初ブリも同Alertに注意表示。**正のボーナス加点は一切なし。**

**Why**: [[feedback-catch-underrated-winners]] の中核=測ってから最適化。風・H2H・調教時計・調教評価A-D に続き俗説5案も「効かない/過剰人気」棚入り。生存している正の妙味は黄金ライン(騎手×調教師)＋厩舎の当コース高勝率(🔴≥20%)のみ([[project-jockey-jv]] / [[project-training]])。
**How to apply**: これら俗説を「効くはず」と再実装しないこと。新シグナルは必ず folk_signals_backtest.py 同様の残差検証を通し、有意に正でなければ表示/注意止まり。
