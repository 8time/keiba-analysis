# verified: 新馬戦限定の騎手×調教師コンビ（黄金ライン新馬版）は有意でない

> **検証日:** 2026-09-07
> **脚本:** `scripts/maiden_golden_line_backtest.py`
> **主張元:** 動画（上昇氏）「新馬戦で特定の騎手×厩舎タッグが異常に高成績。横山武史×伊藤圭三 勝率28.6%/単勝回収値358 等」
> **判定:** **NO-GO（標本不足で有意でない）** — 名門コンビ区分は +2.9pp だが CI が 0 を跨ぐ。新馬戦限定に絞るとコンビ当たりの騎乗数が少なすぎて検出力不足。

## 設計（リーク無し・事前固定）

| 項目 | 値 |
|------|-----|
| 対象 | 各馬の初出走（デビュー戦）。JRA場01-10、芝/ダート、障害除外 |
| シグナル | train（〜2017）の **デビュー戦のみ** で集計した騎手×調教師コンビ成績 |
| 閾値 | 既存定数と同一（GOLD_MIN_RIDES=10、top2 40%/35%/30%） |
| 評価 | holdout（2018–2022）で人気統制後の複勝残差 |
| 副次 | 単勝ROI、holdout コンビ別表（記述統計） |

## 結果（holdout 2018–2022・人気統制後）

| 区分（train の新馬連対率） | n | 複勝率 | 複勝残差 | z | 単勝ROI |
|--------------------------|---|--------|---------|---|--------|
| A: 40%以上（名門） | **397** | 54.9% | **+2.93pp** | +1.39 | 81.0% |
| B: 35-40% | 118 | 36.4% | -2.10pp | -0.54 | 102.3% |
| C: 30-35% | 181 | 37.6% | +2.05pp | +0.66 | 79.6% |
| D: 30%未満 | 4,349 | 20.0% | +0.47pp | +0.75 | 67.2% |
| E: データ少 | 18,740 | 18.9% | -0.09pp | -0.29 | 77.0% |

**bootstrap 95%CI（A）: [−2.37, +7.54]pp → 0を跨ぐ＝有意でない**

- 方向は正（+2.9pp）だが n=397 しかなく検出力不足
- B が負・C が正で単調性なし → 区分としての再現性なし
- 動画が挙げたコンビの ROI（単勝回収値358 等）は holdout では再現しない
  （例: 横山武史×伊藤圭三(01097) は holdout で 11走3勝・ROI 69%）

## 解釈

- 「名門コンビは新馬でも人気以上に走る」可能性は **否定できないが証明もできない**
  （新馬戦に絞ると年間のコンビ騎乗が少数になり、統計的に決着がつかない）
- **全レース版の黄金ライン**（[[golden_line_backtest]]: 連対35-40%帯が最強、50%+は織込み済み）
  がすでに J5 表・妙味スキャナで実装済み。新馬戦でも **既存の全レース版表示を使うのが現実解**
- 「新馬限定に絞った特別な黄金ライン」は作らない

## How to apply

- 新馬戦でも騎手×厩舎は **既存の全レース版黄金ライン（J5表・⭐黄金）をそのまま表示** で足りる
- 新馬限定のコンビ成績表を別途作らない（統計的に不安定な数字を UI に出さない）
- 動画の特定コンビ数字は期間・母集団が不明で再現不可。信用して機械追随しない
