「オッズ理論で他に使えるものは?」を受け、確定オッズの構造仮説をまとめて検証。
scripts/odds_structure_hunt.py（2016-2025・train43万/holdout7万・オッズ帯統制の複勝残差）

**① 断層直上を現代データで再検証(最大の成果)**
core/value_scanner.py: odds_gap_anchors は**90年代データの検証のみ**で
docstringに「要・現代再検証」と明記されていた。今回それを実施し**現代でも有効**と確認:
- 深さで勾配: 1.3倍以上 +0.50/+0.69pp → 1.5倍以上 +0.91/+1.33pp →
  **2.0倍以上 +2.14pp(z+10.6)/+2.54pp(z+5.2)** ＝既定 ratio=2.0 が最強で正しい
- 人気帯: 1-3番人気 +2.12/+2.63 / 4-7番 +1.24/+1.38 / 8-12番 ≈0 / 13番〜 マイナス
  → max_rank=6 の絞り込みも妥当
docstringを更新済み。ユーザーの体感(断層の直上はけっこう来る)は正しい。

**② 圧倒的本命の2番手 → 不採用(レース性質であって馬の性質ではない)**
単体では最大の残差(+7.5/+9.4pp・z+12.7/+6.5)だったが、詰めると:
- 効果は2番手固有でなく**全順位に出る**(holdout: 3番手+7.17/4番手+4.60/5番手+4.55/
  **本命自身+11.25**)＝「圧倒的本命がいるレースは全体が堅い」というレース性質
- 本命の強さに単調(〜1.5倍 +14.5 → 2.5-3.5倍 -1.0 → 3.5倍〜 -7.8)
- 荒れ予報ロジットは1番人気オッズ(fav1)を主要特徴に持つので**大半が重複**
- 単勝ROIは全条件72-89%で買えない
副産物: **本命2倍台自身は-4.07pp(過大評価)** ＝既知の危険人気馬と整合。

**③ 効果なし** 心理的節目(9倍台/10倍台前半)・横並び(上下とも1.1未満)・ブービー人気。

[[verified_antimarket_elim]]の-5.1pp(z-16.5)と符号が逆。統制方法(自オッズ帯で割る)に
敏感なため既存判定は覆さない。要注意点として記録。
