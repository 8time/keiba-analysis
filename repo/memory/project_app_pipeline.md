（旧）4段の予想パイプライン（上記①②③④に吸収。詳細補足として保持）:

1. **レースサーチ**: 市場評価(オッズ)と実力の乖離が大きい馬がいる＝**妙味レース**を抽出（買うべきレースを選ぶ）。
2. **テーブルデータ**: 強適テーブルで上位を絞る（[[kyoteki-score-rebuild-goal]] 勝ち馬top7）。
3. **来ない馬消去**: 過去データから「来ない条件」を推測して消す（消し馬。`scripts/backtest.py`で消し条件のROIを実証してから採用）。
4. **最適な馬券の買い方**: 券種最適化＝同じ予想でも3連複より馬連が美味しい時がある→各券種のEV(=予測確率×現在オッズ)を比較し最大EVの券種/フォーメーションを選ぶ。資金配分は②`kelly.py`(多肢ケリー＋破産確率)。

**Why:** これは典型的なバリューベッティングの絞り込みファネル（+EVレース選定→ランク→剪定→最適ステーク/券種）。回収率の本丸。

**How to apply / 正直な注意:**
- 段1の乖離検出: 自分の予測確率 vs オッズ含意確率(1/オッズを正規化)の差。JV-Dataの**票数(H1/H6)**で大口/異常票（スマートマネー）も検出可。
- 段4「勝ち組の買い方をAI学習」: 個人の勝者が実際に買った馬券データは公開されておらず**直接学習は不可**。現実的な代替＝(a)`backtest.py`で「自分の選定馬に対しどの券種/フォーメーションが歴史的に最大ROIだったか」を学習、(b)票数データで賢い金の流れを検出。この2つで実質同等。
- 段4の券種比較は、各券種の現在オッズ（netkeiba or JV-VAN速報）＋予測確率からEVを出して比較。過去検証はpayouts(HR)で可能。
