「3連複4点の的中31.5%はルーレットのダズン32.43%とほぼ同じだからダズン用の資金管理
(オスカーズグラインド等)が流用できるのでは」を検証。scripts/staking_systems_backtest.py
D鉄板ゾーンの◎〇固定4点・2025-26の2,228レースを実際の並びで回した。

## 類推が壊れる理由＝**配当のばらつき**
| | 当たった時の倍率 |
|---|---|
| ルーレットのダズン | **必ず3.00倍**（ばらつきゼロ） |
| この3連複4点 | 平均2.82 / 中央値2.10 / **最小0.33** / 最大15.9倍 |

**当たっても10%は投資割れ(トリガミ)**。進行法はすべて「1回勝てば直前の連敗を取り返す」
ことを前提に賭け金を決めるので、この前提が成立しない時点で設計が崩れる。
的中率だけが一致しても中身は別物。

## ブートストラップ(500試行×1,200レース・初期10万円・1単位400円)
| 手法 | 退場率 | ROI中央 | 最大DD中央 |
|---|---|---|---|
| **フラットベット** | **2.2%** | **89%** | 62,920 |
| パーレー(逆マーチン) | 64.8% | 85% | 103,695 |
| マーチンゲール | 98.2% | 70% | 120,980 |
| オスカーズグラインド | **99.0%** | 79% | 124,145 |
| ダランベール | **99.8%** | 78% | 130,790 |

**「競馬向き」とされたオスカーズグラインド/ダランベールが最悪**(99%退場)。
緩やかな進行でも、3連複の連敗長(D鉄板でも数十)に対しては賭け金が発散する。
マーチンは50倍上限(2万円/R)に張り付く。

⚠ROIの差(89%〜70%)は**期待値の差ではなく打ち切りの副作用**。
進行法は悪い連敗の最中に退場するので、そこまでのROIが低く測られるだけ。
資金管理は期待値を1円も変えない(数学的事実)。変わるのは分散と生存だけ。

## 結論
**フラットベット一択**。退場率2.2%は他の手法の1/30〜1/45。
[[project_formation_stats]]の必要資金(実測連敗×1.5)と併せて使う。
なお2,228レース全部を10万円で通すとフラットでも尽きる
(89万円投資×ROI89%=-9.8万円)＝ROI<100%である以上、長く続ければ必ず尽きる。
