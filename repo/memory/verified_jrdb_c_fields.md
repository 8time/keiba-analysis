## 一番重要な発見: **プロの印と市場はほぼ一致している**
専門紙の印1位を人気帯で割ると:
| 区分 | n |
|---|---|
| 専門1位 × 1番人気 | **132** (78%) |
| 専門1位 × 2-3番人気 | 37 |
| 専門1位 × 4-6番人気 | **1** |
| 専門1位 × 7番人気以下 | **0** |

**専門紙250人の集合知が推す馬は、ほぼそのまま1番人気**。
「プロの評価 vs 市場」というズレを突く余地が**構造的に存在しない**。
これは標本サイズの問題ではなく、そもそも比較対象が同じものを見ている。

理由は明快で、**専門紙の印を見て馬券を買う人が多いから、印がオッズを作っている**。
独立した第二の情報源ではなく、オッズの上流にあるだけだった。
