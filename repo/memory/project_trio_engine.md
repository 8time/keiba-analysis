**パターンセレクター検証(2026-06-16, scripts/trio_selector_backtest.py, 27,124R/2018+)**: ユーザー要望=「①/②/おまかせのどれを買うか上手く当てて12R中6→7的中」。検証結論=**『どの形になるか』を事前に当てるのは無理**。1番人気の確定オッズで堅/中/荒に層別しても①(人気2穴1)は全層で44-49%とほぼ一定→荒れ度セレクターの的中率46.4%＝①固定46.4%(差ゼロ)。**②(人気1穴2)は最も荒れる層ですら22%止まり＝単独狙いは割に合わない**。的中を上げる唯一の正解=**人気上位2頭を必ず軸に入れ3頭目に人気3番手〜穴を広く流す＝『鉄板(37%)+①(46%)』同時カバー=83%**(全層で鉄板+①が最頻、荒でも鉄板+①75%>①+②71%)。これが実戦で「おまかせ(C)が一番当たった」の正体。トレードオフ=鉄板配当は中央値~15倍(ほぼトリガミ)・①は~71倍。→6→7の最短路は②単独列を減らし軸2頭固定の鉄板+①カバーに寄せ、荒れと読んだ時だけ3頭目の穴を厚くする。形当てではなく軸2頭固定で底上げ。

**②廃止＆本線パターン導入(2026-06-16, ユーザー決定=案A)**: 検証を受けUIの「狙うパターン」を3択(①/②/おまかせ)→**2択『本線(人気2頭軸＝鉄板+①)』『おまかせ』**に簡素化(迷い削減)。②(人気1-穴2)は的中15.5%/ROI最低のため盲目買いを廃止、穴取りは妙味シグナル(🔥🎯🚀=末脚救出/単複乖離/合議市場軸)が鳴った馬だけ3頭目に厚くする方式に肩代わり(②の中身を検証済みエッジに置換)。実装: trio_engine `_match_pattern` に `'本線'`=n_pop>=2、`_TARGET_BAND['本線']=(10,150)`(鉄板~15倍〜①~71倍をカバーしつつ安すぎ<10は軽く減点し①寄り配当へ)。app.py radio key='te_pattern_v2'(旧te_pattern値の混入回避)・_pat_key={'本線':'本線','おまかせ':'おまかせ'}。①②は_match_patternに温存(エンジン後方互換)。

**②穴妙味狙いとして復活(2026-06-17, ユーザー決定)**: 6/14阪神12Rの実戦で本線版5/12<旧版6/12(※差1R＝統計的に誤差・小サンプル罠だと明言済)。ユーザー判断=本線(新①)は残し・おまかせを消し・②を『①と別方向＝妙味/穴特化』で復活。最終UI2択=**本線 / ②穴妙味狙い(人気-穴-穴)**(radio key='te_pattern_v3')。盲目的②は検証で最悪(15.5%/ROI60%)のため『ナマ復活』はせず、穴選別を検証済みエッジに寄せた実装: trio_engine `_match_pattern['②妙味']`=n_pop<=1 and n_ana>=2(本線n_pop>=2の補集合=荒れレース)、`_TARGET_BAND['②妙味']=(30,2000)`高配当帯。スコアリングで②妙味時は妙味シグナル穴(🔥🎯🚀/妙味/乖離)を+18(通常+8)で強加点し、シグナル穴を含まないトリオは-12で後退(=盲目的人気1-穴2を買わない)。スモーク確認: ②妙味の最上位が本命1頭+🔥穴2頭の人1穴2形になる。位置づけ=本線(堅・的中83%)と②妙味(荒・本線の取りこぼし穴レース)の相互補完。

**②妙味バックテスト完了(2026-06-17, scripts/trio_ana_value_backtest.py, 2021-25・16,029R・人気≤4/穴6-12)**: 🔥末脚シグナル(末脚指数で代理)で穴を選別すると②は良くなるか検証。結果=**盲目②(穴全部買い)=的中11.6%/74点/ROI60.4% → 妙味②(穴≥1頭が末脚指数≥0.8)=的中6.1%/31点/ROI77.8%**。**末脚signalでの穴選別はROIを+17pp改善・買い点数を半減**(穴選びを検証済みエッジに寄せるのは正解)。**「≥1頭signal」が最適**(両方signal要求=ROI43.7%で絞りすぎ→現エンジンの≥1で買い/0signalは-12後退がちょうど最良を実装)。thr=0.8>0.6(69.0%)でライブ採用値が正しい。**限界**: ②形で勝つレースのうち末脚signalが穴を捉えるのは18%だけ(残り82%は取れない)→妙味②は『②の高品質サブセットを効率よく取る』フィルタで的中率は下がる(量より質)。ROIはまだ<100%でフラット黒字化せず(控除率25%壁)。役割分担=的中回数を増やすのは本線、②妙味は本線の取りこぼし荒れで高配当を効率良く。
