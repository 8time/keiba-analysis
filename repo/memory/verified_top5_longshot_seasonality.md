ユーザー観測(2026-07)「最近3着内のうち2頭がランク5以内・もう1頭がランク7圏外(8位以下)の決着が
多い。夏競馬で波乱が多いから？」を検証。scripts/top5_plus_longshot_backtest.py。

**代理指標の注記**: ユーザーの『ランク』=強適Ranking Tableの順位(予測スコア順)だが、これは各レースの
netkeibaライブ取得が必要でオフライン大量再現不可。→ **単勝人気順位を代理**(強適Rankは市場オッズに
強相関、"伏兵=市場が期待してない=人気薄"は人気順位で定義できるため妥当)。ユーザーも代理でOKと合意。

**検証(JRA平地 2016-2025・3着馬が全員ninki有りの3頭決着で分類)**:
決着タイプ内訳(全体): 堅(3頭とも5位以内)36% / 2頭5位以内+1頭中位(6-7位)23% /
★2頭5位以内+1頭伏兵(8位以下)23% / 1頭5位以内+2頭中穴以下15% / 0頭5位以内(大波乱)1.5%。

**★パターン(2頭5位以内+1頭伏兵8位以下)の発生率=通年ほぼ一定**:
- 夏(6-8月) 23.52%(n9,007) vs その他期 23.20%(n27,104) → 差+0.32pp(SE≈0.44%)=ノイズ
- 最近(2024-25) 22.93% vs 過去(2016-23) 23.39% → 差も誤差内
- **夏も最近も増えない=季節性/時代性なし**。むしろ最近の夏は堅い決着(3頭5位以内)が39.2%と平常より高め、
  大波乱(0頭5位以内)も通年1.5%前後で一定=夏が特別荒れる事実は無し。

**結論**: ①パターンは実在し"よくある"(約23%=4レースに1回・堅い決着に次ぐ2番手)=ユーザーの体感は正しい。
②ただし夏/最近で増えるは否定(たまたまでなく構造的定数)。③「2頭5位以内+1頭が5位圏外(6-7位+8位以下)」を
合算すると23+23=**約46%**で既知の[[project_trio_engine]]「人気2-穴1が最頻46%」と一致=上位2頭軸+3頭目に
伏兵流し(本線/②妙味・◎軸×combo馬流し)が最頻決着を捉える構造だと再確認。

**How to apply**: 「夏は荒れる」系の季節性仮説が来たら、まずこの型(月別発生率の誤差評価)で検証してから語る。
体感の"よく見る"は頻度が高い(23%)ことの正しい認識だが、"最近/夏に増えた"は別問題で要検証。
