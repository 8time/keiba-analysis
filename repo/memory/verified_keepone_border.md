🎯強適消去エンジンが3着内馬を消しすぎ・救出が発火しない件の微調整(2026-06-17・ユーザー要望)。app.py内の既存ロジック修正(新moduleなし)。

- **末脚救出の閾値バグ修正**: 旧版は `末脚指数(spurt_index) >= 0.8`(絶対値)。だが実測のspurt_indexは概ね-0.7〜+0.6で0.8未到達→**一度も発火していなかった**(2026-06-14の取りこぼし11頭の末脚指数 最大0.594)。検証済み妙味ゾーンの定義は[[verified_spurt_index]]の通り「末脚指数の**レース内top3(順位)**×人気≥6」(複勝13.4%/ROI77.7%>ベース9.4%/66.4%)。→ 事前パスで `df` 全頭のspurt_indexを順位付けし top3 馬番集合 `_spurt_top3` を作り、`_spurt = (_um in _spurt_top3 and _sr>=2 and _pop>=6)` に変更。妙味の穴`_anauma`の人気≥8ゲートは別検証(ROI108.8%)なので温存。

- **🛟ボーダー残し(半分カット後にN頭戻す・0〜3頭スライダー)を新設**: scripts/keepone_backtest.py / keepmore_backtest.py(2023-25・9519R・6頭以上)で検証。戻す馬=消去ゾーン上位(score上位の消され馬≒人気でkeep+k番目)。**累積3着内取りこぼし: 現行14.93%→+1:10.19%→+2:6.61%→+3:4.10%**。各戻し馬単体の3着内人気補正残差: **+1頭目+0.83pt(z=1.97) / +2頭目+1.35pt(z=3.19・最強) / +3頭目+0.78pt(z=1.84) / +4頭目-0.36pt(z=-0.85=人気どおり以下=損)**。→ **戻す価値は+3頭目まで、+4で打ち止め**。どれも単勝ROI70%台=相手(複勝/3連複)専用・単勝軸には入れない。実装: `_keep=(_n+1)//2`以降の上位N頭(index _keep..keep+N-1)を`🛟ボーダー残し`に。N=スライダー(0〜min(3,cut_zone-1)・既定2)。3連複は押さえ(3列目)に自動配置。色=薄青#e3f0fb。「2段構え別条件」は不要(score順位で十分検証エッジ・直交レールは既存の🎯妙味の穴が担う)、最終判断は人間が強適Ranking Tableで。

**ボーダー3は正しい設計と確定(カード3・2026-07-02・scripts/elim_frontier_backtest.py)**: 「弱点フラグ数(elim_cross)を消去順に織り込めばボーダー無しでこぼしを抑えられるか」をtrain2021-24で検証→**却下**。消去スコア=人気rank+W×フラグ数のW選択で**W=0(人気のみ)が最良、W>0はこぼし悪化(train 10.23%→W1:10.67→W2:11.78→W5:15.18)**。フラグは人気に織込み済み([[project_elimination_engine]]のクロス=priced-in)ゆえ、フラグ重み付けは人気の二重計上になり「フラグ持ちだが来る馬」を消してしまう。holdout2025こぼし: 半分カット14.9%→ボーダーON10.4%(=フロンティア最良も同値)、2026=13.6%→9.4%。→**ボーダーは代替不能・撤去しない**。この議論は打ち切り。

**ボーダー数のレース条件による可変化も却下(2026-07-22・scripts/elim_border_regime_backtest.py)**: 「荒れ予報(trio_leanのlean)が②穴妙味向きなら4頭戻す/本線向きなら2頭」案を検証→**却下**。⚠検証の肝=**漏れ率は戻す頭数を増やせば必ず下がる**ので単独で見ると必ず「改善」に見える(V1は対現行-1.42pp)。固定ボーダー0〜5の(平均消去頭数→漏れ率)フロンティアを引いて**平均消去頭数を揃えて**比較すると、全ポリシーがフロンティア比 ≥0＝価値ゼロ: V1(②4/本線2) train+0.10/holdout+0.39pp、V2(荒れだけ4) -0.11/+0.17pp(符号反転)、V3(堅いだけ2) +0.10/+0.17pp、V4(②5/本線1・強め) **+1.16/+1.45pp=積極的に悪化**、V5(lean_score連続) +0.46/+0.62pp。荒れ/堅いの区別はボーダー頭数の最適値を動かさない。なお本線向きは全体の6.6-7.3%しかなく可変の効き代自体が小さい。フロンティア実測(holdout): B0=6.91頭消し/漏れ38.3% → B3(現行)=3.91頭/12.2% → B4=2.99頭/7.0% → B5=2.18頭/4.0%。B4以上を許さない上限3は+4頭目の残差-0.36pt(z-0.85)に基づく既定。

**How to apply/前提**: ✅残し=軸/対抗、🛟=相手専用(単勝軸非推奨)、🧹消し=従来通り。recall重視の中核目標([[feedback_catch_underrated_winners]]/[[project_app_pipeline]])に直結。末脚順位化と🛟は別エンジン[[project_elimination_engine]]の救出を実効化する微調整。ボーダー廃止は却下済み(上記)。
