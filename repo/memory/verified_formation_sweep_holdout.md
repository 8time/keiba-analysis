「点数を減らせば/条件を足せばROI100%を超えるのでは」を train(2016-23)/holdout(2024-26) で決着。
scripts/formation_sweep_holdout.py（128形×荒れ度7ビン×2券種を総当たり）

## ① 選抜バイアスを定量化した（最重要）
trainで最良の形を選び、holdoutで追試した結果:
- 3連複: train平均 **100%** → holdout平均 **68%**（**-32pp**）
- 3連単: train平均 **110%** → holdout平均 **87%**（**-23pp**）
- holdoutで100%を超えたビンは 3連複1/7・3連単2/7 で、しかも一貫しない
  （荒れ度80-200はtrain115%→holdout **0%**）

「探せば100%超が見つかる」は事実だが、**その2〜3割は選抜で作られた幻**。
条件を足して購入数を絞る方向(他AIの提案③)は、この落差をさらに大きくするだけ。

## ② 点数を絞るほどROIが上がる ← これは本物
C中庸(50-69)・全期間・選抜なしでの点数とROIの相関:
- 3連複 **-0.654** / 3連単 -0.371
- 3連複の例: 1点101% → 9点82% → 19点77% → 88点74%
点数を増やすほど市場平均(控除率75%)に収束する。**薄めるほど損**。
アプリのRank上位に情報があることの傍証でもある。

## ③ ただし「1点買い101%」は2017年の幻
3連複 Rank1-2-3 の1点買い(C中庸14,434R)は通期ROI101%だが年別に割ると:
| 年 | ROI |
|---|---|
| 2017 | **295%** |
| 2018 | 128% |
| 他9年 | 50〜83% |
中央値78% / 100%超は**11年中2年**。2017の1年が通期を持ち上げているだけ。
的中数が年30本前後しかなく、高配当1本でROIが跳ねる。

## 結論
- ゾーンはCが最良(3連単2-4-7でROI88%)だが**それでも100%未満**。「Cだけ買えば勝てる」ではない。
- 資金管理は-EVを+EVに変えない(ケリーはエッジ負なら賭け金0を返す)。
- 実用的な学びは**「点数を絞る」「Cゾーンを選ぶ」「Dと荒れは避ける」**の3点で、
  これは回収率を100%超にするものではなく**負けを浅くする**もの。
