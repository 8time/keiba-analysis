3連複10点圧縮（人気1-7プール・複勝率の積）の holdout2025 一連検証。アプリの `recommend_trio` は未変更。基準モデルは**複勝率の積**（人気合計とほぼ同値）。

**全体捕捉 ≈ 41% は再現する天井**（選定率×10点）。候補を6-9頭に変えても、馬を独自データで削っても、3頭セット相性を足しても、この線から外れない。scripts: `trio_rank10_backtest.py` / `trio_third_leg_backtest.py` / `trio_prune_keep_backtest.py` / `trio_combo_set_backtest.py` / `trio_fuku_miss_profile.py` / `trio_yellow_promote_backtest.py` / `trio_partner_select_backtest.py`。

**41%の内訳（人気1-7・holdout 3,325R）**
- 的中 40.9%
- A 候補外 37.8%（8番以降が3着。10点の並べでは救えない→見送り/荒れレーン）
- B 候補内だが10点外 21.2%（中央17位。11-20位が全体13.2%=高配当側）

**レーン**
- 通常（3着が5番以内）: 複勝積で残し内92%。市場に任せる。
- 中穴（3着が6-7番）: 候補には入るが10点捕捉30%。研究対象はここだけ。
- 荒れ（8番以降・1番飛び・妙味度70+）: 10点圧縮と相性悪い。無理に当てに行かない。

**切り分け（2026-08-24 holdout）**
- レベル1「6-7番を3着候補にする」: 馬単位では VH上位で3着内 +5.4pp、末脚×VH で +8.7pp。継続可。
- レベル2「6-7番と組む相手2頭」: **凍結**。X固定の相手15通りで実際の相手順位の中央は複勝積が **4位・1位的中24.8%**。脚質実測/ルール・位置・33・血統・能力はすべてこれより悪い。train でも同じ。
- 10点枠: 相手の上位を安定して拾うには約5点が要るが、鉄板を削ると通常92%が壊れる。鉄板8+相手2でも全体は41%のまま。

**採用ゲート（今後の特徴量）**
holdout で **複勝積を超えたか** だけを見る。超えなければ不採用。相手2頭を展開/33/血統/能力で入れ替える提案は再実装しない。

**How to apply**: 相手2頭は市場（複勝積/人気）。モデルが触ってよいのは 6-7番を3着候補として見るか（VH等）だけ。能力合計は10点用として弱い。`recommend_trio` の順位付けを独自相手スコアに置き換えない。[[verified_tenkai_priced_in]]（展開は馬券エッジにしない）と同型。
