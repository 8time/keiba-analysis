アプリ再構築（時期はユーザーが指示する。今は着手しない）の中核目標。

**メイン機能 = 強適テーブルのテーブルデータ**（`calculate_strength_suitability`等が出す各項目・数値）。ここにJRA-VANデータ由来の数値も加える。

**目標**: それら項目の**総スコア**で、実際の勝ち馬が**上位7頭以内**に表示されるようにする。手段＝(1)数値のコントロール、(2)計算式の創出、(3)不要項目の削除、(4)アプリ既存の「**影響率（ウェイト）**」機能の最適化（`.score_weights_jockey.json`＋UIスライダー）。

**鉄則（ユーザー明言）**: 1レースだけ偶然うまくいくのはダメ。**10レース全部に当てはまる汎化した計算方法**を見つける。

**Why:** 強適テーブルが予想の主軸。勝ち馬を上位7頭に安定して入れられれば、買い目の母集団が正しくなり的中・回収率が上がる。教材は[[catch-underrated-winners]]（安田記念シックスペンス取りこぼし）。

**How to apply（再構築時）:**
- 「勝ち馬が上位7頭以内」= **recall@7 / NDCG@7** であり、これは**Learning-to-Rank（LambdaRank, rank:ndcg）が直接最適化する目的関数**。影響率の手調整ではなく、LTR/最適化で自動チューニングするのが本筋（[[jravan-jvlink-setup]]の研究柱と一致）。
- 過学習回避: 10レースで最適化しても、評価は**アウトオブサンプル（別レース/未来）＝ウォークフォワード**で。`scripts/backtest.py`の枠組みで「勝ち馬top7率」を指標化して検証する。
- 不要項目の削除＝特徴量選択（情報利得等）で寄与の低い項目を落とす。
