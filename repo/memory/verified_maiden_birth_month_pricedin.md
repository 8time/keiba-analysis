# verified: 新馬戦「早生まれが強い」は priced-in

> **検証日:** 2026-09-07
> **脚本:** `scripts/maiden_birth_month_backtest.py`
> **主張元:** 動画（上昇氏）「1月生まれ勝率11.3% vs 6月以降5.4%。生まれ月はオッズに反映されない」
> **判定:** **NO-GO（priced-in）** — 素の成績差は本物だが、人気統制後の残差はゼロ。市場は織込み済み。

## 設計（リーク無し・事前固定）

| 項目 | 値 |
|------|-----|
| 対象 | 各馬の初出走（デビュー戦）。JRA場01-10、芝/ダート、障害除外 |
| シグナル | `horses.birth` の生まれ月 / デビュー時月齢 |
| ベースライン | 人気別 勝率・複勝率（train で凍結） |
| 分割 | train 〜2017 / holdout 2018–2022（birth カバレッジ 100% の範囲） |
| 主指標 | 複勝残差（人気統制後）。残差≈0 なら priced-in |

## 結果

### 素の成績（holdout・統制なし）— 動画の主張は事実として再現

| 生まれ月 | n | 勝率 | 複勝率 |
|---------|---|------|--------|
| 1月 | 1,112 | **11.7%** | 30.9% |
| 2月 | 4,296 | 8.8% | 24.7% |
| 3月 | 7,146 | 6.6% | 19.7% |
| 4月 | 7,139 | 5.8% | 18.1% |
| 5月 | 3,830 | 5.1% | 15.5% |
| 6月 | 222 | **2.3%** | 11.3% |

→ 動画の「11.3% vs 5.4%」とほぼ一致。**早生まれが強いのは事実**。

### 人気統制後の残差（holdout 2018–2022）— こちらが本質

| 区分 | n | 複勝残差 | z | 単勝ROI |
|------|---|---------|---|--------|
| A: 1-3月生まれ | 12,554 | **+0.44pp** | +1.18 | 84.3% |
| B: 4月生まれ | 7,139 | -0.05pp | -0.11 | 64.8% |
| C: 5月生まれ | 3,830 | -0.92pp | -1.36 | 70.4% |
| D: 6月以降 | 262 | +0.17pp | +0.06 | 15.7% |

**bootstrap 95%CI（A・holdout）: [−0.22, +1.09]pp → 0を跨ぐ＝有意でない**

→ 「生まれ月はオッズに反映されない」という動画の核心主張は **JRA データでは不成立**。
素の強さは確かだが、その分すでに人気（オッズ）に織り込まれており、買い妙味は残っていない。

### 副次所見（参考）→ 再検証で破棄（2026-09-07）

- 月齢 Q4（デビュー 35ヶ月以上）の複勝残差 −2.71pp（z=−4.33）を探索的に発見
- → **2023年で前向き再検証したところ −2.12pp / z=−1.57 で事前固定ゲート（z≤−2.0）未達。破棄**
  （`scripts/maiden_late_debut_recheck.py`）
- 教訓: 探索的発見は同データ内で有意でも前向きで縮む。閾値の再最適化はしなかった

## ライブ利用の可否（結論とは独立）

- jravan `horses.birth` は **2023年デビュー馬から欠損**（2023: 76.6% / 2024: 8.5% / 2025: 0.2%）
- 現在の出走馬の生まれ月を取るには netkeiba 馬プロフィール取得の新規パイプラインが必要
- **仮に作っても priced-in なので作る意味なし**（本検証の結論）

## How to apply

使わない。新馬戦パネル等に「早生まれ」を妙味材料として出さない。
参考表示する場合も「素の成績差はオッズ織込み済み」であることを併記しないと誤解を招く。
