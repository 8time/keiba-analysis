JRDB **KYI_2025.zip**（2025年109開催日・47,884行）を追加購入なしの手持ち分で読み、
出馬表からは取れない外厩・帰厩系2俗説を検証した。2026-08-27。
スクリプト: `scripts/kyi_layoff_kikyo_backtest.py`、要約: `data/kyi_layoff_kikyo_summary.json`。
前段の39件一括検証は [[verified-folklore-unverified-batch]] 参照。

## KYIで実際に取れることの確認（ユーザーの第1目的）
- 放牧先(50byte・充足100%)、放牧先ランク(A-E・96%)、入厩年月日(100%)、入厩何日前(57%)。
- **入厩何日前は (レース日−入厩年月日) と n=27,713 で100%一致** → 空欄分も日付から自前計算可能。
- jravan との結合は (開催日, 場コード, R, 馬番) で 2025全出走の **99.5%** が一致。場コードはJRA-VANと同じ01-10。
- その他の使える列: ブリンカー(1:初装着/2:再装着/3:継続…充填11%)、降級フラグ、クラスコード、条件クラス、
  輸送区分、特定情報◎○▲△×(他社印の印数→skip_news_honmei系の検証材料)、基準オッズ。
- **毛色はKYIに無い**（UKC馬名マスタ or KTA）。「芦毛の夏駆け」はこのzipでは検証不可。

## 検証結果

### skip_nf_layoff「NF外厩の中9週以上・1番人気は買い」→ **否決(R)**
- NF&中9週&1番人気: n=359, 勝率33.4%（非NF対照33.9%・全体33.7%）→ 資料の36.6%vs29.9%は再現せず。
- 複勝残差 +0.3pp z=0.3。上半期+0.9/下半期-0.6で符号不安定。
- NF&中9週&全人気では残差-1.4pp **z=-4.6**（むしろ人気ほど走らない=外厩ブランドの過剰織込み側）。

### skip_kikyo「11〜13日前の最短帰厩でラスト1Fが速い馬」→ **保留(U継続)**
- 帰厩日カーブ(入厩後1走目): 7-10日 -1.4pp / **11-13日 -0.8pp z-1.8** / 14-17日 +0.4 / 18-21日 +0.7 z+2.7
  / 29-45日 -0.8 z-4.1 / 46日+ -3.1pp z-7.7。「11-13日が特別」という形状は無い。
- +ラスト1F上位半分(jravan training直近7日・下半期限定): n=417で+1.0pp z=1.3 → 方向+だが有意未達・標本不足。
- 却下基準(n>=2000のz≈0)にも採用基準にも届かず。

## 知見（次回以降に効く点）
- 帰厩日は「長すぎ」(46日+=入厩後1走目で滞在長い)が明確に悪い(-3.1pp z-7.7)。俗説本体よりこちらが強い信号。
- KYIは `scripts/jrdb_read.py` でそのまま読める（仕様書 data/jrdb/spec/kyi_doc.txt 済み）。
  必要列だけに絞ったレイアウトでパースすると47,884行が数秒で読める。
- 検証単位はKYIが2025年分のみのため1窓。採用判定には複数窓が必要ならKYIの翌年分購入が要。
