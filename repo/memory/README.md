# 検証台帳（memory）— このフォルダは何か

このプロジェクトで**実データ検証して結論が出たこと**を1件1ファイルで記録したもの。
AIアシスタントの作業メモが元だが、**中身はツールに依存しないただのMarkdown**なので、
Obsidian / VS Code / 他のAIツール、どれでもそのまま読める。

- **索引は `MEMORY.md`**。まずここから読む。
- 本体は `~/.claude/projects/.../memory/` にあり、ここはそのバックアップ（同期は手動）。
- ファイル内の `[[別ファイル名]]` は関連リンク（Obsidian記法）。

## なぜバックアップするか
本体は `.claude` 配下＝**特定ツールの管理下**にあり、ツールを乗り換えると
アクセスできなくなる恐れがある。ここに置けばリポジトリと一緒にGitHubへ退避される。
※このリポジトリは**非公開**であることを確認済み（2026-08-16）。手の内が外に出ない前提。

## 命名の意味
| 接頭辞 | 中身 |
|---|---|
| `verified_*` | 検証が終わった主張。**採用したものと棄却したものの両方**がある |
| `project_*` | 進行中の作業・設計判断・データ基盤の状態 |
| `feedback_*` | ユーザーからの方針・好み（作業の進め方） |
| `reference_*` | 外部資料へのポインタ |

## 読むときの注意
- **棄却の記録が多い**のは失敗ではなく資産。「なぜ効かないか」を数字で残すことで、
  同じ俗説が再提案されたときに即座に判断できる。
- 各ファイルの日付時点の観測。**コードの行番号や関数名は古くなっている可能性がある**ので、
  実装の話は必ず現在のコードで確認してから使う。
- 数字は原則すべて実データのバックテスト結果。出典スクリプトが `scripts/*.py` に対応する。
