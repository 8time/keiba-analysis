第2弾「賢い金の学習＝どの条件×券種が歴史的に+ROIか」を単勝で総当たり検証(scripts/roi_pattern_backtest.py・2016-2026・n=485,017・既存odds/payouts・win_odds実値)。

**結論: 単勝に+ROIポケットは存在しない=市場は効率的。**
- 母集団 単勝ROI 72.8%(控除後ベース)。
- 人気別: 全部47〜82%(★無し)。オッズ帯別: 55〜86%。**資料の「単勝5〜10倍=期待値ゾーン」は否定**(5-7倍78.6%/7-10倍80.5%)。
- 条件別 最善は**ハンデ×4-9番人気85.3%**だが<100%([[verified_arare_conditions]]のハンデ=②穴寄りと整合・でも単勝では取り戻せない)。10-15倍が83.5%で最高だがやはり負け。

**「賢い金の学習」の答え**: 単純な条件/オッズ帯選びで単勝は抜けない。勝ち筋は①見送り(レース選択)②券種最適化(トリガミ回避・EVプラスのみ)③点数を絞る=**既存の🎩コンシェルジュ(concierge_review)の方針が実データで正しいと裏付け**。穴の妙味は「条件で単勝を買う」ではなく検証済みエッジ([[verified_corrected_time]]補正T/[[verified_spurt_index]]末脚)を**複勝・相手**で拾う一択([[verified_5run_theory_debunk]]とも整合=補正系の単勝妙味は全部織込み済み)。

**第2弾 H1票数取込は不要と判断(2026-06-21)**: 単勝票数≈オッズ(オッズは票数から算出)＝情報重複。40年オッズ既存＋そのオッズに+ROIポケット無し→H1単勝票数を数時間取込んでも新情報ゼロ。上乗せ候補は①直前オッズの"動き"(既存core/odds_tracker・odds_history.dbでライブ検出可・取込不要)②クロスプール(馬連/3連単票数H6の偏り・巨大取込・効果未知)のみ。jvdata_parserにparse_h1/h6は未実装のまま(意図的)。

**券種別ROIも全滅(scripts/bettype_roi_backtest.py・2016-26・34,812R)**: 複勝/馬連/ワイド/馬単/3連複/3連単で人気ベースの標準戦略を実払戻検証→**全部66〜84%で+ROIゼロ**。複勝1番人気84.1%が最善(最も控除軽い側)、3連単1→2→3番人気66.3%が最悪(控除27.5%)。**どの券種も機械的人気買いは負け=市場効率的**。
- 実用知見: **控除の軽い順=複勝・ワイド ＞ 馬連・3連複 ＞ 馬単 ＞ 3連単**。同じ妙味なら軽い券種が有利・3連単は最も不利。
- 最終結論: 券種選びに歪みは無い。勝ち筋は①検証済みエッジで過小評価の勝ち馬を選別(補正T/末脚を複勝・相手)②コンシェルジュ(見送り/点数絞り/トリガミ回避)の2つのみ。

**3連複フラット掛けROIの細分検証(scripts/trio_flat_roi_backtest.py・2021-25・軸1番人気10点流し)**: 相手構成3種×trio_leanフィルター4種でROI総当り→**全セル<100%(+ROIポケット無し)**。最善=本命型(相手2-6番)×本線向き81.2%(的中54.9%)だが控除を少し戻すのみ。重要事実3つ: ①**穴を厚くするとROIは悪化**(本命型77.5%→中穴型74%→穴厚型64.4%)=平均配当UP(2057→4769円)は的中率暴落(37.7%→13.5%)を補えない=資料の「穴を厚く=回収率UP」は不成立。②**trio_leanは的中率/分散の道具でROI製造機ではない**(本線向きで的中率54.9%と当たるが配当も連動しROIは平均収束)。③追い上げ(toto_escalation)で破産確定済み([[project_betsync_money]])。→残る唯一のROI検証=相手を人気順でなく検証エッジ(補正T/末脚/道悪血統の過小評価穴)で選ぶ「消去軸1頭+エッジ流し」。

**本丸=エッジ流しROI検証(完了・scripts/trio_edge_flow_backtest.py・2021-25・軸1番人気10点)**: 相手の穴3頭を末脚偏差(リーク無し直近3走上がり3F偏差)で選ぶvs人気順で選ぶ。結論=**末脚エッジでも3連複ROIは控除を抜けない**。穴の深さを6-12番人気に固定したフェア比較で末脚上位3頭ROI73.9%(的中19.5%)vs末脚下位3頭71.7%(的中17.0%)=末脚上位が+2.2pp/的中+2.5pp上回り[[verified_spurt_index]]通り「同深さなら末脚上位が来やすい」は本物。だが①+2.2ppは小さく②穴妙味フィルターで符号反転(72%<77%)=ノイズ域②どれも100%未満で単純本命型77.0%にすら届かない③実戦版EDGE流し(全≥6番で末脚上位=深追い)は69.4%でむしろ悪化。**末脚エッジは複勝/相手の質・的中率を上げる道具で3連複ROIを控除超えにする力は無い**=市場は穴選別まで効率的。一連(追い上げ✗/レース選別✗/穴厚✗/エッジ流し✗)で「どう買うかだけでは控除を抜けない」が全角度から確定。勝ち筋=①見送り②点数絞り③エッジは複勝/相手/的中率・分散管理(コンシェルジュ方針)。

**未検証で残る余地**: オッズ"変動"の歴史的検証(jravan O1-O5は最終スナップ1点で変動不可・要live odds_history蓄積)。相手を検証エッジで選ぶ3連複ROI(消去軸1頭+エッジ流し)。
