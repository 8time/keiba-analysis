プレミアム予想動画の『初勝利理論』『タイム指数理論』の検証。
scripts/first_win_theory_backtest.py。初勝利を特定できた17,504頭。

主張: G1/重賞を勝つ馬は初勝利時に ①上がり最速 ②上がり2位と0.6秒差以上(芝) の共通点。
着差でなく『上がり差』なので馬場に左右されない、が売り文句。

## 結論: **主張は事実。ただし馬券には使えない(完全にpriced-in)**

### (a) 主張の真偽 → **事実だった**
| 区分 | n | その後の重賞勝ち率 |
|---|---|---|
| 芝・全体 | 8,290 | 8.06% |
| 芝・上がり最速のみ | 3,351 | 11.58% |
| **芝・最速×0.6秒差以上** | 499 | **16.63%(全体の2.1倍)** |
| ダート・全体 | 9,214 | 1.29% |
| **ダート・最速×0.6秒差以上** | 1,069 | **3.46%(2.7倍)** |

### (b) 馬券に使えるか → **ゼロ。しかも符号反転**
該当馬の"初勝利より後の全レース"で人気統制後の複勝残差:
| 区分 | train〜2023 | holdout 2024+ |
|---|---|---|
| 芝・該当馬 | +0.88pp z+1.44 | **-0.69pp z-0.72** |
| ダート・該当馬 | +0.68pp z+1.56 | +1.12pp z+1.61 |

bootstrap(芝holdout): -0.69pp **95%CI[-2.37,+1.00]で0を跨ぐ**。
閾値スイープ(芝holdout)は 0.3秒+0.12 / 0.4+0.77 / 0.5-0.06 / 0.6-0.72 / 0.8**-2.01**。
0.8秒だけマイナス有意だが5閾値中1つ＝多重比較の範囲。**fade材料としても採用しない**。

→ 「強い勝ち方をした馬は後に走る」は本当だが、**市場も同じものを見ている**ので
オッズに織込み済み。むしろ厳しい条件ほどマイナス方向に振れる兆候がある。

## タイム指数理論『上位3頭から95%以上絡む』→ 数字のマジック
新馬戦3,133レースで「3頭のうち1頭でもその後どこかで3着内」率:
| 選び方 | 率 |
|---|---|
| 上がり上位3頭 | 93.0% |
| **ランダム3頭** | **80.3%** |
| 上がり下位3頭 | 53.0% |

選別に意味はある(93% vs 53%)が、**ランダムでも80%**。
「95%」の大半は選別ではなく**「馬は何度も走るから、そのうち1回は3着内に入る」**が作っている。
しかも『いつ・どのレースで』を言っていないので**馬券として実行不能**。
[[verified_roi_claim_credibility]](券種×回数が無い数字は評価不能)の系譜。
