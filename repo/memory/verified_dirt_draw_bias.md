The Dirt Blueprint(ダート設計図)資料の主張を残差ベースで検証(scripts/dirt_blueprint_backtest.py・2021-25・ダート平地・n=176,723)。

**検証済エッジ(実装済):**
- **ダート外枠(6-8)×1-3番人気: 複勝残差+4.5pp(z+9.4)** = 非常に強い軸補強。ダート人気馬の外枠は市場の過小評価。
- **ダート内枠(1-3)×4-5番人気: 複勝残差-3.9pp(z-6.0)** = 危険人気。内枠の中位人気馬は過剰人気。
- **芝スタートコース×内枠: 複勝残差-1.2pp(z-4.6)** = 内枠の危険が芝スタートで増幅。
- **砂かぶりリバウンド(前走ダート内枠着外→今走外枠)×人気上位: 複勝残差+3.4pp(z+3.6)** = 軸補強。人気薄は残差ゼロ([[verified_comeback_overbet]]と同型)。

**priced-in(実装しない):**
- 大型馬500kg+: 全体-0.3pp(z-1.2)。良馬場では-0.8pp(z-2.3)=むしろ過剰人気。
- 道悪×脚質: 全馬場×全脚質で残差≈0。「道悪で前がさらに有利」は織込み済み。
- クラス×差し馬: 上級×後型-2.7pp(z-2.0)=差し馬はむしろ過剰人気。
- 外枠×穴帯(6番人気~): 残差0〜-1.3pp=priced-in。
- 差し馬ROI 77%: [[verified_legtype_axis]]で否定済。77%<100%でそもそも負け。

**Why:** 資料の「ダートは外枠有利/大型馬有利/差し馬ROI高い」は生の勝率差であり、オッズに織込み済み。残差で見ると穴帯のエッジは全てゼロ。真のエッジは「人気馬の軸品質(1-3番人気がどの枠で信頼できるか)」と「危険人気(4-5番人気がどの枠で落ちるか)」に集中。

**How to apply:** core/track_bias.dirt_draw_signal()新設。app.pyのSRAエビデンス表とRace Scannerに配線済み。ダートレースで自動判定。
