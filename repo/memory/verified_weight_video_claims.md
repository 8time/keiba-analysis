動画主張（馬体重は増減数字だけで消すな。特に＋20kgは嫌われて単回収93）を
`scripts/weight_video_claim_backtest.py` で再現（JRA平地 CSV n=437,315。
見る=〜2024 / 確認=2025 / 直近=2026-03〜。リーク無しの過去好走体重は shift 済み）。

判定ゲートは既存どおり。穴馬＝6番以下・両窓 z≥+2 かつ残差>0 かつ n≥200。
危険＝1-3番・両窓 z≤−2。単ROIの生数字は参考（万馬券1本で跳ねる）。

## 生数字は動画とほぼ一致（見る窓・全体）

| 区分 | 動画 | 当データ |
|---|---|---|
| 400kg未満 複勝 | ~7% | 7.1%（単ROI22%） |
| 500-539kg 複勝 | ~25% | 24.7%（単ROI79%） |
| 540kg超 | 複はやや低下・回収優秀 | 複23.2% / 単ROI85% |
| −10〜−19kg | 複17.3% / 単68 | 複17.3% / 単ROI67% |
| −20kg以下 | 複10.2% / 単47 | 複8.6% / 単ROI48.5% |
| ＋20kg以上 | 複17.9% / 単93 | 複17.1% / 単ROI94% |

「数字の表」自体は嘘ではない。

## 残差にすると買い妙味は消える

同オッズ帯の期待複勝との差（これが増減で市場が過剰反応したかの物差し）:

- **大型500-539kg**: 残差 ≈0（織込み済み）。540kg超は見る窓 **−1.46pp (z−2.40)** でマイナス。単ROI85%は控除（単勝約80%）をわずかに超えるが、穴馬ゲートは未達。
- **−10〜−19kg**: 残差 **−1.03pp (z−3.73)**。切るほど極端ではないが、**嫌われ不足＝まだ買われ過ぎ**。確認窓も負。
- **−20kg以下**: 残差 **−4.41pp (z−3.80)**。成績は明確に悪い。確認窓は n=134 で標本不足。
- **＋20kg以上**: 残差 **−1.46pp (z−2.17)**。単ROI94%は当たる単勝が荒いだけで、**複勝では期待より来ていない**。6番以下の確認窓は残差+0.76pp z+0.29＝ノイズ（単ROI124%は1年のブレ）。
- **＋3〜＋9kg 全体**: 両窓 z≤−2 → 唯一のゲート通過は **fade（買い妙味なし）**。既存の馬体増+8kgデバフと整合。

## 動画の「核心」（能力上位なのに体重で人気落ち）

補正Tレース内4位以内 × ＋10kg以上 × 6番以下:

- 見る: n=3,872 複残差 **+1.52pp z+2.28** 単ROI83%
- 確認: n=433 複残差 **+2.67pp z+1.34**（z不足）単ROI **54%に崩壊**

方向は面白いが確認窓でゲート未達、かつ単回収が壊れる。**実装しない。**

過去好走時体重±4kg / 12kgズレ、若馬の増、夏の減、札幌函館小倉・遠征の減は、いずれも両窓ゲート未達。

## 最終扱い（エンジンは変更しない）

馬体重は予想の主役ではなく、相手選びの微調整。

| 要素 | 判定 | 対応 |
|---|---|---|
| 大型馬ほど複勝率が高い | ○ | 人気込み。新規加点なし |
| −10〜−19kg | △ | 数字だけで消さない |
| −20kg以上 | △ | 警戒材料。新規消しルールにはしない |
| ＋10〜＋19kg | △ | 数字だけで消さない |
| ＋20kg以上 | ❌ | 「買い」にしない |
| 馬体重増加による人気落ち | ❌ | 期待値ルールにしない |
| 過去好走時体重との一致 | △ | 補助情報として見る程度 |
| 年齢 × 馬体重 | ❌ | 採用しない |
| 夏 × 馬体重減 | ❌ | 採用しない |
| 長距離輸送 × 馬体重減 | ❌ | 採用しない |
| 滞在競馬 × 馬体重減 | ❌ | 採用しない |

運用の目安:

- 🟢 ±10kg程度 → 基本的に気にしない
- 🟡 大幅増減 → 他の条件と合わせて見る
- 🟠 小柄＋大幅増減 → 相手優先度を少し下げる（既存 stress_debuff）
- 🔴 ＋20kgだから買い → 採用しない

生データが正しい ≠ そこから導いた攻略法が正しい、の典型。ロジック置き場「【保留】馬体重動画・エンジンに入れない（2026-08-24）」。
