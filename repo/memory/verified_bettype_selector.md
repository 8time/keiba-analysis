| C + その他 + fav 2-3 | 3連複 |

## F. アプリ実装の価値

- **現時点では「推奨券種」UIの実装価値は低〜中**。holdout でも全券種 ROI<100% が基本。
- **ただし券種選択の考え方自体は有効**:
  - **第1段階（券種）**: D鉄板→3連複 / C中庸→NNV 3連単 / 1強・2強→3連複 / 上位拮抗→NNV（n小注意）
  - **第2段階（フォーメーション）**: 3連単なら NNV 2-4-7、3連複なら playbook 2点 等
- **NNV 2-4-7 の位置づけ**: 券種=3連単を選んだ後のフォーメーション。ライブ playbook には未配線（`_nnv_rrv_whatif.py` のみ）。
- **馬連/馬単**: holdout ROI は3連複と同程度。1着を強く読める条件でも単独最良にはなりにくい。
- 実装するなら: `zone + pop_struct + fav1 + cross_n` から券種ヒントを出し、買い目は既存 playbook / NNV に委譲。UIは検証後。
