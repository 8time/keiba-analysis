インフォグラフィックの「牝馬限定/新馬/ハンデ/重馬場/フルゲート=荒れる」を検証(scripts/condition_arare_backtest.py・2021-25平地tosu>=8・n=15,462レース・**1番人気オッズ帯で統制**)。指標=本線決着(1・2番人気が両方3着内、母集団31.1%)と②型決着(3着内に5番人気以下が2頭以上=人気-穴-穴、母集団28.0%)。

**オッズを超えて荒れる独立エッジ(②穴妙味向きの根拠にできる):**
- **ハンデ戦(juryo='1')**: 本線-3.8pp(z-2.7) / ②型+7.9pp(z+5.2)。最強。
- **フルゲート16頭+**: 本線-2.2pp(z-3.9) / ②型+3.4pp(z+5.9)。
- ハンデ×16頭: ②型+10.1pp(z+4.7)で相乗。

**堅い独立エッジ(本線向きの根拠):**
- **少頭数8-10頭**: 本線+8.4pp(z+8.3) / ②型-10.7pp(z-11.9)。鉄板寄り。

**オッズ織込み済み=②根拠にしない(検索フィルタとしてのみ):**
- 牝馬限定: 本線+0.2pp(z+0.2)/②型+0.2pp(z+0.2)=ゼロ。フォーク。
- ダート戦: ②型+0.7pp(z+1.4)非有意 / 芝戦も-0.7pp(z-1.5)非有意。
- 新馬: DBのrace_nameに「新馬」未格納で分離不可。元々🚫見送り(情報不足)扱い→買い対象外。

**牝馬限定の判別**: races.kigo(競走記号コード3桁)の**2桁目=='2'**が牝馬限定(検証:平地11.5%・優駿牝馬/桜花賞/ヴィクトリアM/各牝馬S全部該当・ダービー/天皇賞/有馬で誤検出0)。ハンデ=juryo='1'。ライブ側はscraper metadataに`is_fillies`(RaceData02に「牝」)・`is_handicap`を追加済。

**実装(2026-06-18):** core/value_scanner.`trio_lean(meta,n_horses,fav_odds,pace_z)`=本線⇔②穴妙味スコア(ハンデ+2.0/フルゲート+1.5/少頭数-2.0/オッズ/ペース。牝馬・ダートは加点ゼロ)。🔍Race Scanner(Batch)に①3連複決着タイプ絞り込みradio ②特別条件multiselect(牝馬限定/ハンデ/新馬/ダート) ③本線/②穴妙味バッジ＋色分け条件タグ。🏆Race Analysis Summaryヘッダにも色付き条件タグ。

**動画『荒れやすいレースの条件』の追加3項目を検証(2026-07-23・scripts/course_arare_backtest.py・16,251レース・同じく1番人気オッズ帯で統制)=全て不採用**:
- **小回りコース(中山/小倉/福島/函館)**: 全窓②型残差 z+2.87 だが**2025単年で z+0.31 に崩落**。小倉単体が最強(全窓z+3.24)だが副窓z+1.23で未達。
- **短距離(≤1200m)**: 全窓 z+2.35 → 2025 z-0.11(符号も逆)。
- **重・不良馬場**: 全窓 z+2.24 → 2025 z+1.65(惜しいが未達)。
- **小回り×短距離**: 全窓 z+2.47 → 2025 z-0.22(符号逆)。
→ **全窓のz2〜3は5年分の検出力で拾えるだけで単年に割ると消える**。「小回り/短距離/道悪は荒れる」は事実だが、その荒れは1番人気オッズが既に織込み済み(統制後の上乗せが年をまたいで安定しない)。**既検証のハンデ/フルゲート(z5前後・両窓一貫)とは検出力が一桁違う**。trio_leanに足す価値なし＝検索の目安どまり。動画5条件の対応: ハンデ✅/フルゲート✅(独立エッジ・実装済) / 牝馬限定・2歳世代限定・メイン路線外GⅠ(=priced-in or 情報不足で買い対象外) / 小回り・短距離・道悪(今回検証→priced-in)。
