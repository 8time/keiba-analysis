## 背景
1年半の検証で残ったのは「中心の並び順を当てること」ではなく
**「本命の信頼度を測ること」**だった（Rankは全ゾーンで市場に負ける／
荒れでも人気1・2を外すと壊滅／最良は◎〇+人気3-4位）。
部品は揃っていたが43列のテーブルや各所のバッジに散らばり、一目で答えが出なかった。

## core/fav_check.py
`check(fav, horses, race)` → verdict / items / race_ctx / note を返す。
**新しい主張は一切足していない。** 使うのは検証済み部品のみ:
| 部品 | 実測値 |
|---|---|
| danger_gate.danger_veto | 材料0個54.3% / 1個51.4% / 2個47.7%（10.8万頭） |
| glass_favorite_fade | 複勝率残差 z-8.5（3窓一貫） |
| 前走1着 / 位置比率<0.28の先行 | -2pp / -1.6〜1.9pp（両窓★・両方持つと-4.6pp） |
| is_golden_line | 騎手×厩舎連対率35%+ で +2.44/+2.48pp（77.5万騎乗） |
| race_axis_confidence | 補正T×人気の重複0→3で1番人気複勝率 55%→74% |
| **人気とRankの食い違い** | Rank7-9位 -1.86pp / **Rank10位以下 -4.21pp(z-7.45)**（[[verified_rank_fav_disagree]]） |

判定は**効果量で重み付け**した合計で決める（同じ「NG1個」でも強さが違うため）:
- w=2: ガラス(z-8.5) / **Rank10位以下(-4.21pp)** / 危険材料2個(-6.6pp) / 前走1着と先行の両方(-4.6pp)
- w=1: 危険材料1個(-2.9pp) / Rank7-9位(-1.86pp) / 前走1着のみ(-2pp)
合計 0=🟢 / 1-2=🟡 / 3+=🔴

## 設計で踏んだ落とし穴2つ
1. **ガラス人気馬はdanger_gateの理由にも入っている** → そのまま数えると
   二重カウントになる。danger側の理由から`ガラス`を除外して1回だけ数える。
2b. **重み無しだとRank8位とRank12位が同じ🟡になる**（-1.86ppと-4.21ppで
   効果量が倍以上違うのに同列）→ w を持たせて合計で判定。
3. **レースの堅さ（補正T重複）は馬の落ち度ではない** → 総合判定に混ぜると
   良い本命が堅くないレースにいるだけで🟡になる。判定から外し`race_ctx`枠で
   文脈として別表示する。

## 表示（SRAの軸信頼度の直後）
`st.container(border=True)` の2カラム。左に🟢/🟡/🔴と推定3着内率、
右に各項目の✅⚠️と**実測値つきの理由**。最下部に必ずこの注意を出す:
> 「来る／来ない」ではなく「**オッズに見合うか**」を見ています。
> 危険材料が2個ついた馬でも実測の複勝率は47.7%で、半分近くは3着以内に来ます。

これは[[verified_danger_fav_audit]]の「材料が付いても半分は来る＝
『来ない予言』ではなく『オッズに見合わない』印」を毎回伝えるため。
