3連複の決着タイプ別 配当分布を検証(scripts/trio_payout_by_type.py・2016-2026・34,812R)。

**決着タイプの発生率と配当帯:**
- **本線(①: 1・2番人気が両方3着内)**: 発生31.4%・中央値**1,520円**・四分位[850〜2,920]円。0-3千円に76%。＝安い鉄板。
- **その他(中間)**: 発生40.6%・中央値4,820円・四分位[2,660〜9,200]円。
- **②型(穴2頭: 5番人気以下が2頭以上3着内)**: 発生28.0%・中央値**24,250円**・四分位[**11,970〜55,420**]円。
  配当帯分布: 3-7千(30-70倍)9.4% / **7-15千(70-150倍)22.5% / 1.5-3万(150-300倍)24.3% / 3-7万(300-700倍)23.1%** / 7万~(700倍~)19.8%。**約9割が70倍以上・約7割が70〜700倍**。

**How to apply(馬券フィルター)**: ②穴狙いは**3連複オッズ70〜700倍(7千〜7万円)を取りにいく**のが母数最大。安すぎ(<70倍=本線価格・既に人気)と超高額(>700倍=宝くじ)は外す。本線狙いは10〜30倍中心。
**実装(2026-06-21)**: core/trio_engine.py `_TARGET_BAND` の②妙味を(30,2000)→**(70,800)**、②を(80,1000)→(70,700)に是正(従来は広すぎて30-70倍の本線価格まで②扱いだった)。[[project_trio_engine]]。提案数は20/30/50追加済(②穴は的中が後半ランクに散るため点数増で拾う)。

**関連の確定事実**: 単勝~3連単すべて機械的選択は+ROI無し([[verified_tansho_roi_efficient]])。なので馬券フィルターの狙いは『+ROI』でなく『同点数で的中率/価値を上げる＝当てにいく絞り』。穴脚の選別は検証済みエッジ([[verified_corrected_time]]補正T/[[verified_spurt_index]]末脚)、荒れレース選別は[[verified_arare_conditions]](ハンデ/フルゲート)＋[[verified_heavy_track_bias]](重不良)、危険人気馬除外も同。
