「何頭まで絞れば5着以内を取りこぼさないか」をレース性質別に出す機能。実装済み。

**検証** scripts/narrow_n_backtest.py
- train 2020-2024(17,276R)で 荒れ予報帯×頭数帯 ごとに必要頭数を実測
- holdout 2025+(5,105R)で**全9層が目標80%をクリア**(平均カバー率83.2%/平均7.7頭)
- 一律7頭だと79.3% → 層別で+3.9pt。「荒れる時だけ広げる」が効く

**表の中身**(data/narrow_n_table.json)
- 堅い(〜40%)×〜11頭 → 6頭 / 堅い×12頭以上 → 7頭
- 中間(40-55%) → 7〜8頭
- 荒れ(55-65%) → 8頭 / 大荒れ(65%〜)×15頭以上 → 9頭

**設計**: 新モデルを作らず、検証済みの value_scanner.arare_prob と頭数だけで引く
実測テーブル。順位付けは人気順が基準([[verified_top5_capture_ceiling]]で
LTRは人気を超えないと実測済みのため)。core/narrow_n.py の recommend()/label()。

**配線先**
- 🏠SRA: 荒れ予報の直後に st.info で表示
- 🧹消去クロステーブル: 固定だった「目標6〜7頭」を推奨頭数に差し替え、
  達成/絞りすぎのバッジもこれ基準に変更

⚠これは「買う点数」ではなく**消し過ぎの警戒ライン**。買い目点数はEV/資金管理で別に決める。
