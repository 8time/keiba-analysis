JRDB（https://jrdb.com/）を導入した場合に、**台帳で「データが無くて止まっている」項目**が
どれだけ解けるかの整理。2026-08時点。

## 現在データ不足で止まっている検証（棚卸し）
| 止まっている検証 | 不足しているもの | 出典 |
|---|---|---|
| 締切前オッズでr40複勝EVが再現するか | 時系列オッズ(91Rしかない) | [[verified_r40_place_ev]] |
| パドックの主観項目(歩様/発汗/気配) | 過去履歴が皆無 | [[verified_paddock_weight]] |

| 前走で不利を受けた馬の逆張り | レース中の不利データが無い | 未検証（資料でのみ言及） |

| オッズ変動(大口投票の検知) | 時系列オッズが無い | [[verified_odds_structure_hunt]] |

## JRDBで解けるもの（確認済みの提供項目）
- **SED(成績データ)** に テン指数 / 上がり指数 / ペース指数 / **馬体コード(6段階)** /
  **気配コード(8段階)** が入っている（jrdb.com/program/Sed/sedsiyo_doc.txt で確認）
- **IDM不利補正**＝「出遅/位置取/不利」からなる補正値があり、
  前不利・中不利・後不利は**レース映像の分析に基づく**補正値
- **時系列オッズ**(基準オッズと実オッズの比較)、**外厩**、パドック情報、調教分析、直前情報

## 期待値の見立て（台帳の実績から）
| 項目 | 見立て | 根拠 |
|---|---|---|
| **レース中の不利(前/中/後)** | **最有望** | 完全に未検証。かつ「映像を見ないと分からない＝市場が織り込みにくい」情報の典型 |
| **時系列オッズ** | **確実に必要** | r40複勝EVの最後の未検証点がこれ一つ。無いと実運用に進めない |
| パドック(馬体/気配コード) | 有望 | 履歴が遡れれば[[verified_paddock_weight]]のphase Bが即実行可能 |
| 外厩 | 未知 | 台帳に全く無い新情報 |
| 調教評価・脚色 | やや期待薄 | 調教**時計**は4.4万頭で完全にゼロだった。評価/脚色は別物だが分は悪い |
| 馬場差・素点 | 小 | 補正タイムを既に自前較正済み(本命補強に+5pp)。上位互換でも伸びしろは限定的 |
| **IDM/各種指数** | **価値薄** | ①テン/ペース/上がりは[[verified_pace_congestion_weak]]でpriced-in確定 ②**JRDBの指数は広く流通しているので市場に織り込まれている**と考えるべき |

## 重要な原則
**「加工済みの指数」より「生の観測データ」を狙う。**
IDMのような完成品は多数のユーザーが同じものを見て買うのでオッズに反映される。
一方、不利・馬体コードのような生データは各自の解釈が要るため歪みが残りやすい。
[[verified_dbkeiba_jcombo]]（他社の加工済み条件が両窓で符号反転した例）と同じ理屈。

## 過去データの年数（2026-08 会員ページで実確認済み）
| バックナンバー | 範囲 | 年数 |
|---|---|---|
| **直前情報** | **2010年1月30日以降** | **16年** |
| PDF新聞 | 2013年以降 | 13年 |
| 各種新聞 | 2004年9月18日以降 | 22年 |
| Target用各種データ | 2016年以降 | 10年 |
※1999年〜2010年1月の直前情報は「JRDBデータ」「各種新聞バックナンバー」側で提供とのこと
＝**アーカイブ自体は1999年まで遡れる**。

**これで r40複勝EV の最後の未検証点が過去データだけで潰せる**。
自前で締切前オッズを貯める必要すらない（16年 × 約3,900頭/月 ＝ 70万頭規模）。
既存のCSV特徴ストア（2016-2026・48万頭）より長い。

## 導入前に決めておくこと
- **過去何年分を買えるか**が全て。1年分ではまた[[verified_training_and_sire_popbucket]]の
  二の舞（train/holdoutに割れず「候補」止まり）。最低5年、できれば10年欲しい。
- ⚠第三者の「ROI207%」等の数字は鵜呑みにしない。
  [[verified_roi_claim_credibility]]の通り、券種と試行回数が無い数字は評価不能。
- 配布物への転載は不可（他社の加工物）。[[project_newspaper_pub]]の線引きを踏襲し
  **自分の計算にのみ使う**。
