## 検証結果
- **全体**: 庭25.8% vs 遠征27.1%(z=-0.51) → 庭がむしろ劣る

- 全帯で|z|<2、符号もバラバラ=一貫性なし
- 場別: 船橋のみ庭+8ppだが他3場は遠征が同等or上
- 庭騎手の平均人気6.6 > 遠征6.1 = 市場は遠征騎手をより高く評価(腕の差が織込み済み)
