根拠が66R台帳しかなかったので1-3番人気を10.8万頭(holdout 1.5万)で測り直した。
scripts/danger_fav_audit.py（オッズ20分位で統制した複勝残差・train≤2024/holdout2025+）

**実装への反映(core/danger_gate.py)**
- 斤量比≥12.6% と 前走5着以下 を削除。警告本数だけ増やしseverityを水増ししていた。
  旧コメントの「前走5着以下 train-1.5/holdout-1.8pp」は**オッズ統制前の値**で、
  同じ人気でもオッズが緩い分を拾っていただけ。
- 前走逃げ をソフト→硬いへ昇格(旧コメントは「残差+0.005≒0」だったが実測は-2.8〜-3.3pp)。
  [[verified_front_runner_overbet]]と整合。

**ユーザー指摘への答え(重要)**
材料が付いても来るのは仕様。holdoutの複勝率は 材料0個54.3% / 1個51.4% / 2個47.7%。
最強の重不良×1番人気ですら**絶対複勝率57.6%＝まだ6割近く来る**。
危険材料は「来ない予言」ではなく「オッズに見合わない」印であり、
切ると損。軸の格下げと配分減に使うのが正しい。この文言をUI/docstringに明記済み。
