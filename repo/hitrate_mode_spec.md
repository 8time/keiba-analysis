# 当たり優先モード（仕様書のみ）

## 定義

ゾーンごとに **1レースあたりの予算を固定**し、予算内で「ROI下限（既定85%）を満たす検証済み候補のうち、的中率が最大の買い方」を選ぶモード。

| ゾーン | 1レース予算 |
|--------|------------|
| D 鉄板 | 400円 |
| C 中庸 | 3,000円 |

予算固定により、例えば D ゾーンでは「2点×200円」と「4点×100円」を同じ投資額で比較でき、差は的中率と損失/100円だけになる。

## 候補の確定方法

候補は `scripts/hitrate_shape_search.py`（および関連バックテスト）の出力から、人手で確定する。自動切替は行わない。

## UI文言案

> 当たる回数は増えますが、当たったときの払戻は小さくなります。1レースに使う金額は同じです。

## 実装範囲

**本案件（N1〜N6）の範囲外。** 成績表示への損失/100円・投資/1的中の追加（N4）のみ実装済み。券の中身を変えるモード切替は holdout / shadow 検証後に別案件とする。
