# 少頭数×先行 1セル検証

> 実装しない。セルを先に固定してから train → holdout を見る。
> ここで再現しなければ、条件付き俗説の研究は一旦打ち切る。

---

## 0. いま何を確かめるか

俗説有効度（0〜100）は凍結した。次にやる検証は **1セルだけ**。

問いはこれだけ。

**少頭数の先行馬は、人気が織り込んだ期待を超えるか。**

「先行だから買い」ではない。全体の先行は、生の3着以内は高いが残差はマイナス（織込み）。
少頭数だけ例外かどうか、を1回測る。

---

## 1. やってはいけないこと

- 頭数の閾値を 10 / 12 / 14 に動かして一番良いものを残す
- 逃げ・内枠・差しを2セル目として足す
- 場・芝ダ・人気帯で切って、良かった交差だけ残す
- 有効度スコアや Rank / 穴馬 / 3連単に足す
- `recommend_trio` / `fixed_pool` のシグネチャを変える
- 新ライブラリを足す

holdout で +3pt が出なければ、俗説系の条件探しは止める。

---

## 2. 覗き見の告白（このセルを選んだ理由）

`scripts/folklore_effectiveness_backtest.py` の holdout 探索表示で、

- 先行 × 頭数〜11頭: n=1113 複42.2% 残差 **+5.55pp** z=+4.47

が出た。だからこのセルを選んでいる。**holdout は完全な未知ではない。**

それでも1セルに固定して測る意味は、次の紛れを潰すため。

少頭数は 3着以内が 3/N なので、**全馬の複勝率が上がる。**
前回の残差は「全頭数の人気別ベース」だった。少頭数なら内枠も逃げもプラスに見えた。
先行の話なのか、少頭数の話なのか、を先に切り分ける。

覗き見があるので、採用条件に **train でも同じ符号** を入れる。
holdout だけプラスなら採用しない。

## 3. セル定義（これ以外にしない）

| 項目 | 固定値 |
|---|---|
| 俗説 | 先行 = `pos_ratio3 <= 0.28`（有効度BTの `style_senko` / 俗説 `front_habit` と同じ向き） |
| 少頭数 | `field_size <= 11`（探索表示の `~11` と同じ。10頭に寄せない） |
| 比較の多頭数 | `field_size >= 15`（中間の 12–14 は主判定に使わない） |
| 脚質 | 当該レースの通過・結果脚質は使わない。CSV の過去平均だけ |

該当0は「先行ではない」。`pos_ratio3` 欠損も先行ではない。

## 5. 先に固定する比較（これ以外の表を採否に使わない）

少頭数のインフレを見るために、次の5群だけ出す。

| 記号 | 定義 |
|---|---|
| CELL | 先行 かつ 頭数≤11 |
| COMP | 非先行 かつ 頭数≤11（同じ少頭数の残り） |
| BIG | 先行 かつ 頭数≥15 |
| ALL_S | 先行（頭数不問） |
| ALL_F | 頭数≤11（脚質不問） |

主指標は複勝残差。生の3着以内率・単勝ROIは併記するが、率が高いだけでは採用しない。

残差のベースは2本。両方出す。採否は **B_cell**。

| ベース | 中身 |
|---|---|
| B_global | train 全体の人気別 3着以内率（前回と同じ。少頭数インフレが乗る） |
| B_cell | train の **頭数≤11だけ** で作った人気別 3着以内率 |

B_cell は「少頭数の中での人気の目安」なので、CELL と COMP の差が先行の話になる。

補助（採否には使わない。符号の確認用）:

- 少頭数レースで、先行が1頭以上かつ非先行が1頭以上あるとき、レース内の（先行平均残差 − 非先行平均残差）の平均
- train の年別符号（CELL の B_cell 残差）

人気帯 1-3 / 4-5 / 6+ は説明用に出すだけ。ここで切って採用しない。

---

## 6. 採否（先に書く）

条件付き俗説の研究を続けるのは、次を **すべて** 満たしたときだけ。

1. holdout の CELL、B_cell 残差が **+3.0pp 以上**
2. holdout の (CELL − COMP) が B_cell で **+3.0pp 以上**（少頭数全体の底上げではない）
3. holdout の CELL が n≥200
4. train の CELL、B_cell 残差が **プラス**（覗き見対策）

+5pp は「かなり明確」の目安で、閾値は +3.0pp に固定する。後から 2.8pp を足して通さない。

満たさなければ:

- 条件付き俗説は打ち切る
- 2セル目を探さない
- トラックバイアスも有効度も、この結果で復活させない

満たしても:

- 有効度 0〜100 は作らない
- この工程ではエンジンに足さない
- 「少頭数の先行は市場を超えることがある」と memory に残すだけ
