# ゴール予想順位の分解監査（2026-09-29）

## 結論と判定

**総合判定は E（本番の過去年再現に必要な発走前保存値不足）。** ただし、発走前のJV過去走だけに限定した代理計算では、4角位置をゴール予想へ変換すること自体は2025年・2026年前半とも有益だった。したがって「4角上位馬を下げる処理は一律に誤り」というB判定は支持されない。2024年固定の4角重み増候補は2025年・2026年とも点推定の改善が微小で、誤差範囲を超える優位が確認できないため、**候補に限ればD（安定した改善の証拠なし）**。本番重み・消去・買い目を変更する根拠は得られなかった。

今回の比較は「ゴール予想の本番完全再現」ではない。2024/25の当時のBattleScore・Suitability・AvgAgari・position_score_map・時刻付き人気・ゴール予想が網羅保存されていない。最終人気入りの計算は明示的に**事後情報を使った診断代理**であり、発走前予測性能として引用してはならない。信頼できる発走前代理は、当該レース前のJV履歴だけで構成した`goal_no_market`である。検証母集団は対象レースと同じ**JRA芝1200m**に限定した。全距離への外挿もしない。

## 2. 構造監査

- 4角の直接重みは**.4/3.5=11.4%**、人気は**1.4/3.5=40%**。この値は因果的寄与率でなく係数比率であり、他の特徴との相関・欠損で実効寄与は変わる。`pos4`が最前でも、人気・総合力の順位が低ければ大幅降格し得る。
- `BattleScore`には過去走由来の速度/Oguraと、短距離で`AvgPosition≤5`なら+15点が入る。`Suitability`にも過去成績・位置・上がり・近況が入る。4角、末脚、総合力、適性は独立ではなく、同じ過去走を複数経路で使う。ただし相関だけで「不当な二重計上」と断定しない。
- `kick`はライブのAvgAgari秒とJVの**相対上がり順位**、`power`はライブのBattleScore点とJVの**過去相対着順**を、馬ごとに欠損代替する。混在があるレースでは尺度が異なったまま全馬順位化される。`predict_finish_shadow`は入力元をフィールド単位でそろえるが、本番の`predict_finish`には未接続。
- `_rank_norm`は大小の方向を正しく統一しており、今回確認した符号逆転はない。一方、差の大きさを順位へ潰す。極端な能力差でも隣接順位と同じ間隔になり、欠損は0.5で固定される。実測値の少ない列は欠損馬が相対的に有利/不利になり得る。
- `calculate_battle_score`はAgariTypeを参照するが、`PassingType=Imputed`を実測4角として排除しないままAvgPositionを作る経路がある。`Passing='8-8'`の初期値が残る例があり、AvgPositionとそれを含むBattleScore、位置スコアへ波及し得る。`AvgAgari=35.0`等の代替値もapp側では正数ならゴール入力に入る。
- `calculate_ogura_index`の現在日時依存、歴史スコアcacheの事後生成、2024/25市場価格の取得時刻不在、pace snapshotの上書きにより、既存DBだけで過去の本番入力は復元できない。JV履歴は`before_key`でレース当日以降を遮断し、読み取り専用で使用した。

## 3. 評価設計とFREEZE

2024年の探索は255レース3,774頭。対象は芝1200m・8頭以上・4角と着順の実測あり・過去履歴がある馬6頭以上。4角上位/ゴール上位は出走頭数の上位40%。2024年の**正の順位低下の上位四分位**から「大幅降格」を**8位以上**と固定した。比較は4角単独、発走前JV履歴のみのゴール代理、最終人気入り診断代理、最終人気のみの事後oracle、各1特徴除去、4角重み.4→.7の1候補に限定。2025年へ閾値とモデルを固定し、2026年6月21日までの追加確認では対象6頭と確認済み過去走レースを除いた。対象レースの結果を条件選択に使っていない。

## 5. 発走前代理のOOS比較・Ablation

確率校正は2024年の単一スコアへのロジットだけで固定。2025/26には再学習せず、各レース予測上位5頭のPrecision/Recall、全馬のAUC等を比較した。Brier差の区間はレース単位600回の対応bootstrap。

最終人気入り**診断代理**の特徴除去では、2025年、4角を外すとBrier .1396→.1402（悪化、対応差−.000634、95%区間−.001128～−.000121）。4角情報は小さくても追加価値がある。一方、kick除去で.1385、power除去で.1381と良くなったが、これはJV代理の相対上がり/過去相対着順の評価であり、ライブAvgAgari/BattleScoreの否定ではない。2026ではkick除去は.1317と点推定改善だが区間は0を跨ぎ、power除去は.1330と悪化した。適性とspurtはこのJV代理で定数/重み0なので評価不能。補正タイム・騎手・血統等はゴール式の独立項目でなく、単独除去は定義できない。

唯一試した4角重み.4→.7は、2025年Brier .1396→.1395、2026年.1328→.1323という小差。ただし対応bootstrapで元モデル−候補の差は2025年**+0.000094**（95%区間−.000268～+.000444）、2026年**+0.000481**（−.000128～+.001049）で、どちらもゼロを跨ぐ。2025年上位40% Recallも.7468→.7455と改善しない。候補数は1で、本番採用しない。

較正例として2025人気なし代理の0–20%帯は平均予測11%/実績12%（2,169頭）、20–40%帯29%/28%（1,284頭）、40–60%帯45%/45%（343頭）。確率はこの代理の値で、本番購入確率ではない。前方残存研究のStage 2 Brier .2045→.2030は**実測前方のみ**という別母集団のため、この全馬Brierと直接大小比較しない。残存分布形状候補は2026前半に悪化しており、ここで復活採用しない。

## 7. 影響、採否、次に必要な記録

`finish`はSRAの直線図に使われ、そこから後方集合を`rear.json`に保存して消去クロスの`pmback`へ流す。ただし`pmback`は未検証フラグで、検証済み重複数と複勝率帯には入らない。今回の対象レースで「ゴール9位→購入しなかった」という因果は、発走前runに結びついたゴール値と推奨/実購入ticketが欠けるため証明できない。ROI改善・悪化も算出しない。

既存ゴールの**一律廃止**、4角重み増、kick/powerの削除、残存指数追加は不採用。次の検証を可能にする最小限の記録は、race/horse/analysis_run ID、発走予定・予測・取得時刻、過去走の実測/補完区分、4角全中間値、ゴール全入力の元単位と取得元・欠損理由、順位正規化後の値と寄与、各モデル版/コードhash、風設定、4角順位/ゴール順位、後方フラグ、推奨/実購入へのリンクである。上書きせず予測時点のsnapshotを保存し、結果は別レコードで結合する。これが揃うまでは本番のA/B/Cどれかを強く断定できない。
